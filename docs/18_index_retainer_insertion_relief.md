## E. final insertion path — **FAIL**

### E1. 실제 CAD 적용 결과

`INDEX_retainer_insertion_relief` (`FG1ZStRCxmlgyo8_16`) 로
나사 B 보스(r 3.5 + fit 0.25)를 w 방향 18 mm sweep 해 retainer 에서만 뺐다.

```
state = ERROR
solid 19 -> 20,  RWID 소멸 -> R2JD + R2JH 생성  (retainer 2조각 분할)
JaD / JfD 정상 (J1=1, J2=1)
```

→ **§12 의 "retainer body split" 조건 성립.** 즉시 피처를 삭제하고 원상 복구했다.

### E2. 더 근본적인 발견 — 단일 직선 인출은 기하학적으로 불가능하다

retainer 전체가 분할면 X = 0 을 넘으려면 w 방향으로 **41.59 mm** 이동해야 한다.
그 이동의 성분은:

```
+Y (그립 후방)  34.73 mm      <- 그립 내부 공동이 이만큼 깊지 않다
+X (분할면 쪽)  19.69 mm
+Z (위쪽)       11.67 mm
```

**원인 구조:** pad 가 보어에서 빠져나오려면 삽입축이 세 보어축과 **≤ 46°** 여야 하고
(pad 3.6 / 보어 6.4 / 돌출 1.35 에서 유도), 세 보어축은 대부분 **−Y(전방·외측)** 을 향한다.
따라서 인출 방향은 필연적으로 **+Y(후방)** 이 지배적이 되고, 그 방향으로는 34.7 mm 를
갈 공간이 없어 후방 내벽(face 91)에 걸린다.

> **pad 인출 조건과 분할면 탈출 조건이 서로 반대 방향을 요구한다.**
> 이것은 국소 relief 로 해결되는 문제가 아니다.

### E3. 2구간 병진(회전 없음)도 실패

"−w 로 조금 빼서 pad 를 보어에서 분리한 뒤 +X 로 들어올린다" 를 검사했다.

| | 결과 |
|---|---|
| 1단계 −w 1.5 / 2.0 / 3.0 mm | JfD 충돌 12 / 40 / 108 (보스 relief 로 해소 가능) |
| **2단계 +X 이동** (−w 2.0 후, 탈출에 18.7 mm 필요) | **t = 1 mm 에서 충돌 25 → FAIL** |
| **2단계 +X 이동** (−w 3.0 후, 탈출에 18.3 mm 필요) | **t = 1 mm 에서 충돌 67 → FAIL** |

→ 현재 retainer 는 **어느 단순 병진 경로로도 빠지지 않는다.**
negative-mold 가 공동을 그대로 채우면서 사방에 undercut 이 생긴 결과다.

## 다음 실행 권고 — 2순위 fallback 으로 전환

국소 swept relief 로는 해결되지 않음이 **수치로 확정**되었으므로,
승인해 주시면 **E(w) extractable-region 기반 retainer** 로 넘어간다.

이미 계산해 둔 fallback source:

```
E(w) = 삽입방향 w=(-0.4734,-0.8350,-0.2805) 로 직선 인출 가능한 영역
       약 1,517 mm^3,  세 pad 연결 확인됨
```

E(w) 는 정의상 **모든 점이 w 로 빠져나갈 수 있는** 집합이므로 undercut 이 원리적으로 없다.
구현은 "blank − 홀더 sweep − 보스 sweep − 주 내벽 sweep" 이 아니라
**E(w) 를 직접 다면체로 근사해 blank 로 삼는** 방식이 된다.

다만 E2 에서 밝힌 대로 **분할면 탈출까지 단일 직선으로 하려면 +Y 로 34.7 mm** 가 필요하므로,
E(w) 방식으로 가더라도 **"어디까지를 인출 완료로 볼 것인가"** 를 먼저 정해야 한다.

| 정의 | 필요 이동 | 성립성 |
|---|---|---|
| pad 가 보어에서 분리되면 인출 완료 | 약 1.5 ~ 3 mm | E(w) 로 성립 가능 |
| retainer 가 분할면 X=0 을 완전히 넘어야 완료 | 41.6 mm | **공동 깊이 부족으로 불가** |

**권고:** 인출 완료 기준을 **"pad 분리 + 홀더 클러스터 이탈"** 로 정의하고,
그 뒤의 취출은 자유 운동(사람 손)으로 둔다. 이는 실제 조립 관행과도 맞다.
이 정의를 승인해 주시면 E(w) 방식이 성립한다.
