# OneGrip Play 손가락 모듈 P0/P1/P2 정량 시험 절차

## 1. 목적과 적용 범위

이 문서는 OneGrip Play의 `LEFT / CENTER / RIGHT` 3방향 손가락 입력 구조를 감각적인 평가가 아니라 동일한 수치로 비교하기 위한 절차다.

- **P0:** 손가락 하나의 A/B/C 구조 비교와 V1 메커니즘 선택
- **P1:** 검지·중지·약지·소지 4모듈 배열, 특히 약지·소지 연동 검증
- **P2:** 버티컬 OneGrip 본체, 손바닥 지지, 스트랩, 그립 기울임을 포함한 통합 검증

목표 정확도 `95%`는 초기 공학 Gate이며 임상 성능을 뜻하지 않는다. 사용자의 운동 범위가 크게 다르므로 대상 사용자 멘토 결과는 일반 팀원 결과와 합산하지 않고 별도 열로 기록한다.

## 2. 시험 전 고정 조건

### 2.1 시제품과 출력

- 프린터, 노즐, 필라멘트, 슬라이서 프로파일을 기록한다.
- 기본 출력 조건은 PETG, 0.4mm 노즐, 0.2mm 적층이다.
- A/B/C는 같은 제조사의 같은 로트 스위치를 사용한다.
- 스위치 3개의 작동력을 장착 전 각각 5회 측정하고 평균·범위를 기록한다.
- 모든 모듈에는 스위치 과행정을 막는 독립 하드스톱을 둔다.
- 시험 전 패들 100회 길들이기를 하고 파손·끼임·복귀 실패 여부를 기록한다.

### 2.2 입력 로거

- GPIO를 최소 `1kHz`로 샘플링하거나 모든 원시 에지에 마이크로초 타임스탬프를 남긴다.
- 원시 에지와 디바운스 후 이벤트를 모두 저장한다.
- 비교 시험의 디바운스는 모든 Variant에서 동일하게 `ON 5ms / OFF 10ms stable`로 시작한다.
- 한 물리 동작에서 release 뒤 `80ms` 이내 같은 입력이 다시 발생하면 중복 입력 후보로 표시한다.
- 시험 중 알고리즘으로 다른 방향을 억지로 배제하는 상호잠금은 끈다. 구조 자체의 오입력을 먼저 측정한다.

권장 CSV 열:

```text
stage,participant,hand_size,finger,variant,trial,target,
command_time,first_raw_edge,event_time,release_time,
left_count,center_count,right_count,result,
peak_force_N,reposition,effort_1_5,discomfort_1_5,notes
```

### 2.3 용어와 계산

한 trial의 판정창은 지시 후 `500ms`다.

- **성공:** 의도 방향 이벤트가 1회 발생하고 다른 방향 이벤트가 없음
- **누락:** 500ms 안에 의도 방향 이벤트가 없음
- **이웃 우발 입력:** 의도하지 않은 두 방향 중 하나가 1회 이상 발생
- **중복 입력:** 한 번의 의도 동작에서 의도 방향이 2회 이상 디바운스 이벤트로 발생
- **동시 입력:** 서로 다른 방향의 활성 구간이 `10ms` 이상 겹침
- **반응시간:** 지시 시점부터 첫 유효 이벤트까지
- **복귀시간:** 작동 방향 release부터 세 입력이 모두 중립이 될 때까지
- **재배치:** 손끝 중심이 원래 접촉 캡/지지영역을 완전히 벗어났다가 다시 놓임

계산식:

```text
정확도(%) = 성공 trial / 전체 trial × 100
누락률(%) = 누락 trial / 전체 trial × 100
이웃 우발 입력률(%) = 이웃 입력 trial / 전체 trial × 100
중복 입력률(%) = 중복 trial / 전체 trial × 100
반복 성공률(%) = 유효 이벤트 수 / 지시 비트 수 × 100
```

한 trial에 누락과 이웃 입력이 함께 있으면 두 지표에 모두 포함하되 성공에는 포함하지 않는다.

### 2.4 피험자와 안전

- P0는 팀원 최소 3명, P1은 손 크기가 다른 최소 3명을 권장한다.
- 대상 사용자 멘토는 가능한 범위에서 P1/P2에 참여시키되 피로를 호소하면 즉시 중단한다.
- 피부 눌림, 저림, 통증, 경직 증가, 손가락이 걸려 빠지지 않는 상황이 나타나면 해당 시험을 즉시 중단한다.
- 스트랩은 한 손 또는 보조자가 즉시 풀 수 있어야 한다.
- 힘과 각도 목표는 설계용 수치이며 치료·진단 기준이 아니다.

## 3. 공차 쿠폰과 계측 준비

### 3.1 공차 쿠폰

본 모듈보다 먼저 다음 후보를 한 판에 출력한다.

| 기능 | 후보 CAD 간극 |
|---|---|
| 회전 패들 좌우 간극 | 면당 0.15 / 0.20 / 0.25 / 0.30mm |
| 슬라이더 간극 | 면당 0.15 / 0.20 / 0.25 / 0.30mm |
| Ø2mm 축 구멍 | 2.20 / 2.25 / 2.30 / 2.35mm |
| 스위치 포켓 | 실측 외형 +0.10 / +0.15 / +0.20mm(면당) |

선택 조건은 조립도 쉽지만 눈에 띄는 측면 흔들림 없이 100회 완전 복귀하는 가장 작은 간극이다. 선택값과 실제 출력 치수는 캘리퍼로 기록한다.

### 3.2 필요한 계측물

- 0.01mm 표시 캘리퍼
- 0~2N 범위를 읽을 수 있는 푸시풀 게이지 또는 0.01kg 분해능 저울 지그
- 스마트폰 120fps 이상 슬로모션 촬영
- 입력 로거와 PC
- 손가락 위치 표시용 2mm 점 스티커
- 0.1mm·0.2mm·0.3mm 조절 심
- 육안 검사 확대경

힘은 손끝 실제 접촉점과 실제 작동 방향에서 측정한다. 스위치 플런저를 직접 눌러 얻은 힘을 손끝 작동력으로 기록하지 않는다.

## 4. P0 — 한 손가락 A/B/C 비교

### 4.1 제작 범위

1. 높이·각도 조절이 가능한 책상 고정 지그 1개
2. A/B/C 검지용 카트리지 각 1개
3. A/B 중 우선 두 안의 소지용 캡·레버 프리셋
4. 같은 스위치 로트의 스위치 9개 이상
5. 교체식 `0.1/0.2/0.3mm` 프리로드 심

Variant마다 색만 다르게 하고 로고나 이름은 가려 피험자가 선호 구조를 추측하지 않게 한다. 시험 순서는 참여자마다 `ABC / BCA / CAB`로 바꾼다.

### 4.2 기계 검사

각 Variant에서 다음을 먼저 측정한다.

| 항목 | 측정 횟수 | P0 목표 |
|---|---:|---:|
| LEFT/CENTER/RIGHT 손끝 작동력 | 각 5회 | 검지·중지 0.45~0.70N, 약지 0.40~0.65N, 소지 0.35~0.55N |
| 작동 전 손끝 이동량 | 각 5회 | CENTER 0.6~0.9mm, 측면 1.0~1.5mm |
| 완전 복귀시간 | 각 10회 | 중앙값 ≤100ms, 최대 ≤150ms |
| 패들 측면 유격 | 3점 측정 | 손끝 환산 ≤0.30mm |
| 하드스톱 뒤 추가 플런저 이동 | 각 방향 | 데이터시트 허용 과행정 이내, 구조하중은 셸이 받음 |

손을 올려놓은 중립 상태에서 60초 동안 이벤트가 한 번이라도 발생하면 프리로드 또는 지지면을 수정한 뒤 다시 시작한다.

### 4.3 단일 입력 시험

1. 참여자가 편한 높이와 각도로 지그를 맞춘다.
2. 방향별 10회 연습한다. 연습 데이터는 제외한다.
3. 화면 또는 음성 지시에 따라 LEFT/CENTER/RIGHT를 무작위로 각 30회, 총 90회 입력한다.
4. 각 지시 간격은 1.0~1.5초 무작위로 한다.
5. 손끝 점 스티커를 정면 촬영해 재배치와 측면 이동을 확인한다.
6. Variant 종료 후 effort와 discomfort를 각각 1~5로 평가한다.

**P0 단일 입력 Gate**

- 전체 정확도 `≥95%`
- 각 방향 정확도 `≥93%`
- 이웃 우발 입력률 `≤2%`
- 동시 입력률 `≤1%`
- 중복 입력률 `≤1%`
- 재배치 `≤1회/90 trial`
- effort·discomfort 중앙값 각각 `≤2/5`

### 4.4 반복 입력 시험

메트로놈에 맞춰 다음을 수행한다.

| 방향 | 속도 | 시간 | 목표 입력 수 |
|---|---:|---:|---:|
| CENTER | 4Hz | 10초 × 3세트 | 세트당 40 |
| LEFT | 3Hz | 10초 × 3세트 | 세트당 30 |
| RIGHT | 3Hz | 10초 × 3세트 | 세트당 30 |

세트 사이 30초 쉬고 방향 사이 60초 쉰다.

**P0 반복 Gate**

- 반복 성공률 `≥95%`
- 의도하지 않은 방향 `≤2%`
- 한 세트 안에서 stuck-on `0회`
- 첫 세트 대비 마지막 세트 성공률 감소 `≤5%p`
- 시험 뒤 패들 완전 복귀 실패 `0회/100회 수동 확인`

### 4.5 소지 확인

P0 점수 상위 두 Variant를 소지 프리셋으로 바꿔 방향별 20회와 2Hz 10초 반복시험을 한다.

- 초기 소지 정확도 `≥93%`
- 이웃 우발 입력률 `≤3%`
- 작동력 `0.35~0.55N`
- 지지면에 올려둔 소지 무게로 자동 작동하지 않음
- 소지를 누를 때 약지 surrogate 또는 실제 약지의 동반 접촉을 영상으로 기록

소지 Gate를 통과하지 못한 구조는 검지 점수가 높아도 V1으로 바로 복제하지 않는다.

### 4.6 내구 예비시험

선정 후보 1개에 방향별 500회, 총 1,500회 자동 또는 수동 반복을 가한다.

- 파손·축 이탈·스위치 이동 0회
- 전후 작동력 변화 `≤15%`
- 전후 손끝 유격 증가 `≤0.15mm`
- 정확도 재시험 10회/방향에서 `≥95%`

### 4.7 P0 선택 규칙

1. 안전 중단 또는 소지 Gate 실패 구조는 제외한다.
2. 필수 Gate 통과 구조끼리 `finger_module_tradeoff.md` 점수를 실측값으로 갱신한다.
3. 정확도 차이가 2%p 이내면 손끝 재배치가 적고 소지 점수가 높은 구조를 고른다.
4. B가 통과하면 B를 우선한다.
5. B가 실패하고 A가 통과하면 A를 V1으로 고른다.
6. C는 A와 B보다 정확도가 최소 3%p 높지 않으면 공차 위험 때문에 선택하지 않는다.

## 5. P1 — 네 손가락 배열

### 5.1 제작 범위

- 선택 구조의 검지·중지·약지·소지 카트리지 각 1개
- 손가락 중심 위치 `116 / 86 / 57 / 30mm`를 시작값으로 하는 배열 지그
- 각 모듈 전후 `±8mm`, 회전 `±8°` 조절부
- 손가락 길이와 폭이 다른 캡 프리셋
- 손바닥 하중을 받되 실제 기기 기울임은 없는 고정 그립 더미

### 5.2 맞춤 절차

1. 사용자가 힘을 주지 않고 그립을 잡는다.
2. 중지를 먼저 맞추고 검지, 약지, 소지 순으로 전후 위치를 맞춘다.
3. 손가락 지문 중심이 CENTER 캡 중심에서 `±2mm` 안인지 확인한다.
4. 손톱·DIP 관절·손가락 옆면이 하드 셸 모서리에 닿지 않는지 확인한다.
5. 중립 60초 동안 자동 입력이 없도록 프리로드를 조정한다.
6. 최종 슬롯 위치, 각도, 캡 규격을 사진과 mm로 기록한다.

맞춤시간 목표는 첫 사용자 `≤15분`, 같은 프리셋 재조립 `≤5분`이다.

### 5.3 12방향 무작위 시험

각 참여자는 12개 입력을 각 30회, 총 360회 수행한다. 120회마다 2분 쉰다.

**P1 Gate**

- 12방향 전체 정확도 `≥95%`
- 각 손가락 정확도 `≥93%`
- 약지·소지 각각 P1 수정 후 `≥95%` 목표
- 이웃 방향 우발 입력률 전체 `≤2%`
- 다른 손가락의 우발 입력률 `≤2%`
- 동시 입력률 `≤1%`
- 손끝 재배치 `≤4회/360 trial`

### 5.4 finger-enslaving 교차시험

다음 쌍을 번갈아 각 20회 수행한다.

- 검지 CENTER ↔ 중지 CENTER
- 중지 LEFT ↔ 약지 RIGHT
- 약지 CENTER ↔ 소지 CENTER
- 약지 LEFT ↔ 소지 RIGHT
- 소지 LEFT ↔ 소지 RIGHT

한 방향을 누른 상태에서 다른 손가락을 10회 누르는 chord 시험도 한다. 단, 같은 손가락의 LEFT와 RIGHT 동시입력은 요구하지 않는다.

**교차시험 Gate**

- 지시하지 않은 손가락 이벤트 `≤3%`
- 약지·소지 쌍에서 `≤5%`면 형상 수정 후 1회 재시험 허용
- 손가락이 지지홈 밖으로 빠짐 `0회`
- 한 키를 누른 상태에서도 이웃 손가락 입력 성공률 `≥90%`

### 5.5 반복·피로시험

- 검지·중지 CENTER: 4Hz, 15초, 각 3세트
- 약지 CENTER: 3Hz, 15초, 3세트
- 소지 CENTER: 2.5Hz, 15초, 3세트
- 모든 측면 입력: 2.5Hz, 10초, 각 2세트
- 이후 일반 게임 입력을 모사한 무작위 12키 과제를 15분 수행한다.

**피로 Gate**

- 마지막 세트 성공률 `≥90%`
- 첫 세트 대비 성공률 감소 `≤7%p`
- discomfort 최고값 `≤3/5`, 시작 대비 증가 `≤1점`
- 저림·피부 통증·손가락 걸림 없음
- 소지만 먼저 지지면에서 이탈하거나 과도하게 굽혀지지 않음

### 5.6 P1 내구시험

- 대표 검지 카트리지: 각 방향 3,000회
- 약지·소지 카트리지: 각 방향 1,000회
- 합계 최소 15,000 actuation

전후 조건:

- 작동력 변화 `≤15%`
- 유격 증가 `≤0.20mm`
- 균열·백화·축 이탈·나사 풀림 없음
- 30회/방향 재시험 정확도 `≥95%`

## 6. P2 — OneGrip 본체 통합

### 6.1 통합 상태

다음을 모두 장착한 최종에 가까운 질량·형상으로 시험한다.

- 퍼티형 버티컬 그립
- 네 손가락 카트리지
- 손바닥 지지 및 퀵릴리스 스트랩
- 엄지 입력부 더미 또는 실제 부품
- 좌우·전후 기울임 관절과 고정 베이스
- 실제 배선과 커버

### 6.2 정적 도달·자세 검사

1. 손목을 중립에 가깝게 놓고 스트랩을 고정한다.
2. 네 CENTER, 여덟 측면 입력을 눈을 감고 각 5회 누른다.
3. 손가락·손바닥·손목의 기준점을 촬영한다.

설계 목표:

- 손목 신전 `≤15°`
- 요측/척측 편위 `≤10°`
- 12입력 도달률 `100%`
- 손가락 지문 중심의 캡 이탈 `≤3mm`
- 스트랩이 엄지 운동범위 또는 소지 혈류를 방해하지 않음
- 5분 중립 유지 시 자동 입력 0회

각도는 의료 판정이 아니라 상대 비교용 설계 목표다. 사용자의 구축 또는 관절 제한 때문에 중립이 불가능하면 본인의 편안한 기준 자세 대비 변화량을 기록한다.

### 6.3 기울임 중 입력 교란시험

그립을 좌·우·앞·뒤 최대 사용각의 80%로 유지하면서 손가락 입력을 시험한다.

- 각 기울임 방향에서 12입력을 각 10회: 방향당 120회
- 기울이는 동안 아무 손가락도 누르지 않는 30초 중립 시험
- 2초마다 기울임 방향을 바꾸는 동안 CENTER 입력 40회

**P2 교란 Gate**

- 기울임 유지 중 손가락 정확도 `≥95%`
- 그립 기울임만으로 발생한 손가락 이벤트 `0회`
- 다른 손가락 우발 입력률 `≤2%`
- 손이 그립에서 축방향으로 미끄러진 거리 `≤5mm`
- 스트랩·손바닥 지지가 힘을 받아 소지에만 하중이 몰리지 않음

### 6.4 실제 과제

| 과제 | 시간 | 기록 |
|---|---:|---|
| PC 게임 훈련 과제 | 15분 | 키 정확도, 반복 실패, 손 재배치 |
| 웹/YouTube 조작 | 10분 | 탭 이동, 재생, 전체화면 성공률 |
| 콘솔 메뉴 또는 게임 | 15분 | 기울임과 손가락 동시입력 오류 |
| 휴식 없이 혼합 사용 | 20분 | discomfort, 피로, 자동 입력 |

과제 성공률 `≥90%`, 손가락 모듈 때문에 발생한 명확한 오입력 `≤2%`, 20분 후 discomfort `≤3/5`를 목표로 한다.

### 6.5 최종 내구·정비시험

- 검지 대표 카트리지 각 방향 10,000회
- 나머지 카트리지 각 방향 2,000회
- 본체에서 카트리지 10회 탈착
- 배선 커넥터 10회 탈착
- 체결 나사 토크를 동일하게 한 뒤 입력력 재측정

**P2 최종 Gate**

- 파손 및 기능 상실 0회
- 작동력 변화 `≤20%`
- 이웃 입력률 최종 `≤2%`
- 카트리지 1개 교체시간 `≤10분`
- 교체 후 별도 셸 가공 없이 입력력 심 조정만으로 정상화

## 7. 실패 원인별 수정 규칙

| 관찰 | 우선 수정 | 금지할 임시방편 |
|---|---|---|
| CENTER 때 LEFT/RIGHT 동시입력 | 중앙 가이드 유격 축소, 측면 패들 간극 증가, 하드스톱 앞당김 | 긴 펌웨어 잠금으로 숨기기 |
| LEFT/RIGHT 누락 | 측면 레버비 증가, 접촉각 3° 단위 수정, 프리로드 감소 | 손가락을 크게 옮기도록 안내 |
| 정지 상태 자동입력 | 프리로드 증가, 지지면 높이 증가, 소프트 패드 얇게 | 전체 스위치 감도만 낮추기 |
| 반복 중 복귀 지연 | 축 간극·마찰 확인, 금속축 사용, 패들 질량 감소 | 강한 스프링으로 작동력 증가 |
| 소지 작동력 과다 | 내부 지렛팔 연장, 스위치 후퇴, 전용 소지 패들 | 검지 STL 균일 축소 |
| 약지/소지 교차입력 | 모듈 전후·각도 분리, 지지 능선 조정, 캡 폭 축소 | 해당 입력 삭제 |
| 출력 개체마다 감각 다름 | 공차 쿠폰 재선정, 스위치 슬롯·심 추가 | 매번 수작업 사포질로만 보정 |
| 축·키 백화/균열 | 두께 증가, 적층 방향 변경, 금속축·필렛 적용 | 접착제로 균열만 덮기 |

한 번에 한 parameter만 바꾸고 revision을 올린다. 형상 변경 전후 데이터를 같은 참여자·같은 순서로 비교한다.
