# 75 — N1/N2 제외 통합 최적화 검토 및 수정

검토일: 2026-08-24  
범위: OneGrip Play 전체 시스템 중 `N1/N2 ↔ SZH-EK056` 간섭 문제는 동결·제외

## 결론

N1/N2를 제외한 손가락 스위치 구조와 하부 짐벌·인체공학 하우징은 현재 검증
자료상 다시 바꿀 근거가 없다. 반면 전장 배치는 그대로 최적안이 아니었다.

이번 수정으로 전장은 다음처럼 역할을 분리했다.

```text
움직이는 상부 그립
  ├─ 기존 엄지 버튼 8 + 신규 손가락 버튼 8
  ├─ PCF8575 16입력
  └─ 엄지 조이스틱
          │  8심 유연 하네스
          │  3V3 / GND / SDA / SCL / JOY_X / JOY_Y / JOY_SW / 예비·INT
          ▼
고정 하부
  ├─ RP2040-Zero
  ├─ 전원보드
  ├─ 하부 짐벌 센서
  └─ 외부 USB
```

이 배치는 USB `D+ / D-`를 움직이는 짐벌에 통과시키지 않고, 16개 버튼선을
개별로 통과시키지도 않는다. 하부 짐벌 센서는 고정측에서 RP2040에 직접
연결한다.

## 그대로 유지한 항목

### 손가락 입력부

- `I4 / M3 / I2_I3 / M4_N3` 캐리어: M3 셀프탭 파일럿 `Ø2.5 × 5 mm`
- 쉘 공구 접근홀: `Ø3.4 × 1.2 mm`
- 캐리어·양쪽 쉘 간 하드 간섭: `0 mm³`
- N1/N2는 본 문서의 판정에서 제외

기존 보고서의 설명 중 `M2`라는 문장은 초기안의 잔재다. 실제 최종 치수와
체결 규격은 모두 **M3**이다.

### 하부 짐벌과 하우징

- 하우징 제조안: `REV D`
- 조인트 여유: `0.30 mm/측`
- M4 관통홀: `Ø4.5 mm`
- M4 카운터보어: `Ø8.0 × 4.2 mm`
- ±15° 동작 간섭: 전 자세 `0`
- 최소 최초 접촉각: `15.88°`, 요구각 대비 `+0.88°`
- MAIN·ARMREST STL: watertight, 비다양체·열린 에지 `0`

운동부와 인체공학 외형은 이미 회귀검증을 통과했으므로 전장 때문에 다시
형상을 바꾸지 않는다.

## 수정 1 — RP2040 삽입 방향 여유

실물 피드백에서 17.92 mm 폭은 적합했지만 23.15 mm 길이 방향 삽입이 빡빡했다.

| 항목 | 기존 | V4 |
|---|---:|---:|
| RP2040 폭 방향 포켓 | 18.42 mm | 18.42 mm |
| 폭 방향 여유 | 0.25 mm/측 | 0.25 mm/측 |
| 길이 방향 포켓 | 23.65 mm | **24.35 mm** |
| 길이 방향 여유 | 0.25 mm/끝 | **0.60 mm/끝** |

바로 전체 카세트를 다시 출력하지 않도록 `0.50 / 0.60 / 0.70 mm/끝` 세 칸을
한 번에 시험하는 쿠폰도 추가했다. 생산 선택값은 가운데 `0.60 mm/끝`이다.

## 수정 2 — 전원보드 쪽 외벽 개구 삭제

전원보드는 기존 포켓에 정상 삽입되며 별도 외부 단자 개구가 필요하지 않다는
실물 피드백을 반영했다.

- `+Y` 외벽의 `10 × 4.5 mm` 개구 삭제
- 보드 사이 `10 × 3.2 mm` 내부 배선 게이트는 유지
- 외부 배선은 RP2040 서비스 방향으로 모음
- 연속 외벽이 복원돼 출력 안정성과 이물 유입 방지가 좋아짐

## 수정 3 — 카세트와 짐벌 플레이트

사진과 오픈소스 원본을 다시 대조한 결과, 스프링을 실제로 받는 하부 플레이트는
별도 `CARRIER_PLATE`가 아니라 스톡 짐벌의 `Base`다. `Base`에는 네 개의
스프링 나사 보스가 있고, 움직이는 상부 `Spring_holder`에는 네 개의 대응 귀가
있다. 이전 `CARRIER_PLATE` 결합안은 부품 식별 오류로 폐기한다.

- 원본 고정 하부 `Base`: `100 × 143 × 18.5 mm`
- 중앙 후면 카세트형 돌출부와 단면 벽 제거 후 `Base`: `100 × 100 × 16.5 mm`
- 움직이는 상부 `Spring_holder`: `57.52 × 61.32 × 7 mm`
- 보존 대상: Base 스프링 보스 4개 + Spring_holder 귀 4개
- 카세트 방향: Base 중앙 전면 `-Y`, USB `-Y`, 뚜껑 분리 `+Z`
- 카세트 중심: `(X,Y)=(0,-46.864) mm`
- Base와 카세트 간격: `1 mm`
- 연결 브리지: `30 × 7 × 5 mm`, 양쪽에 각 `3 mm` 물림
- 통합 결과: 유효한 **1솔리드**
- 뚜껑 조립 간섭: `0 mm³`
- 통합 외형: 약 `100 × 146 × 16.5 mm`

추가된 카세트와 브리지는 네 스프링 보스의 보수적 `14 × 14 × 25 mm`
보존 영역과 모두 `0 mm³` 간섭이다. `Pitch / Spring_holder / Roll`은 중립,
축별 `±20°`, 대각선 `±20°`의 9개 상태를 검사했고 최대 간섭도 `0 mm³`였다.
Base 하부와 카세트 하부가 같은 평면이므로 일체형은 같은 출력 기준면을 사용한다.
뚜껑은 별도 부품이라 보드 정비 접근도 유지된다.
빨간 X로 지정된 중앙 후면 돌출부는 원래 스프링 데크 경계인
`Y=76.636 mm`에서 제거했으며, 제거 체적은 약 `10,994 mm³`다.
절단 단면에 남은 중앙 후면 벽도 `X=-15~15 mm`, `Y=69~77 mm`에서
실제 바닥판 상면 `Z=-21.5996 mm`까지만 제거했다. 추가 제거 체적은 약
`672.0 mm³`이며 바닥 두께 `6.5 mm`와 후면 스프링 보스 두 곳은 유지된다.
이전 3.5 mm 가정으로 생긴 3 mm 깊이 단차는 수정됐다. 최종 운동 검사는 설계 목표
중립·축별 `±20°`·대각선 `±20°`로 확대했고 최대 간섭은 `0 mm³`다.

## 수정 4 — PCF8575 위치와 전압

팀에서 사용 중인 보편형 PCF8575 모듈을 `32.2 × 21 mm`로 가정하고, 직선
헤더를 제거한 저상형 설치 봉투를 검사했다.

### 위치 결과

- 채택 후보 중심: 그립 좌표 `(X, Y, Z) = (0, 24, -33) mm`
- 설치 봉투: `23 × 7 × 34 mm`
- 명목 간섭 삼각형: `0`
- `0.4 mm/면` 확장 봉투: 간섭 `0`
- `0.8 mm/면` 확장 봉투: 간섭 발생

완전히 한쪽 쉘에 들어가는 방향도 별도 탐색했으나, 우선순위 후보 20개를
정밀검사했을 때 `0.8 mm/면` 강건 여유를 만족하는 안은 없었다. 그러므로
보드를 무리하게 한쪽으로 밀지 않고 중앙의 검증된 공간을 사용한다. 다만
고정용 엣지 크래들은 한쪽 쉘이 소유하고, 반대 쉘을 열면 보드를 꺼낼 수 있게
한다. 정확한 보드 부품 배치와 무부품 가장자리 실측 전에는 쉘 보스를 합치지
않는다.

PCF8575는 2.5–5.5 V 동작 부품이므로 이 설계에서는 **3.3 V로 구동**한다.
I²C 풀업도 3.3 V에 둔다. 5 V 모듈의 기본 풀업을 그대로 두면 RP2040 쪽과
전압이 맞지 않을 수 있으므로 조립 전에 모듈의 풀업 연결을 확인한다.

## 짐벌 통과 하네스

권장 신호는 8개다.

1. `3V3`
2. `GND`
3. `SDA`
4. `SCL`
5. `JOY_X`
6. `JOY_Y`
7. `JOY_SW`
8. `PCF_INT` 또는 예비선

±15° 제한 회전이므로 슬립링은 필요 없다. 중앙에 느슨한 서비스 루프를 두고
상부·하부 양쪽에 스트레인 릴리프를 둔다. 다만 케이블 외경과 최소 굽힘
반경은 실물 하네스 선택 후 포락선을 다시 검사해야 한다.

## 사람이 직접 조립하는 순서

1. RP2040 길이 쿠폰을 출력해 `0.50 / 0.60 / 0.70 mm/끝` 중 맞는 칸 확인
2. V4 카세트와 뚜껑 디버링
3. PCF8575는 3.3 V 구동·풀업 상태를 책상 위에서 확인
4. 상부 버튼 16개를 PCF8575에 배선
5. 8심 하네스를 상부에서 하부로 통과시키고 양쪽 스트레인 릴리프 고정
6. 하부에서 RP2040·전원보드·짐벌 센서를 배선
7. RP2040을 USB 쪽부터 기울여 넣고 수평으로 안착
8. 전원보드 삽입, 뚜껑 M3 네 개를 대각선으로 체결
9. 중립·±15°에서 케이블 당김과 커넥터 접촉 여부 확인
10. 버튼 16개, 두 조이스틱, USB 연결을 순서대로 기능 시험

## 남은 STOP 항목

N1/N2 외에도 아래 네 항목은 실측 전 확정할 수 없다.

- PCF8575 실제 모듈 외형·부품 높이·무부품 PCB 가장자리
- 전원보드 하부 부품의 XY 위치와 상부 최고 높이
- 선택할 8심 케이블의 실제 외경·최소 굽힘 반경
