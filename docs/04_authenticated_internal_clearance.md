### 결정적 사실

**8개 스위치의 축이 전부 동일한 (0, −0.757, +0.653) 이다.**

→ **docs/01 §2.3에서 PARTIAL로 남겼던 "엄지 영역인가" 판정을 YES로 확정한다.**

버튼 캡 중심 X = ±11.00, ±8.16, 0.00 (part studio) 로, 2D 스케치 분석값과 **완전 일치**했다.

- **주의**: 캡 상면이 곡면을 따라 기울어진다. 평면 캡을 쓰면 모서리가 들뜬다
- OPTION B 로 축을 세우면 측방 하중 문제가 **사라진다** (docs/03 §11의 부가 요구사항 해소)

### M1 상세

- 법선 (−0.94, −0.20, −0.27), 접선각 −77.9°. I1 과 거의 같은 방향
- 내부 여유 **39.4 mm** — 8개 중 가장 여유로운 축에 속한다
- 가장 가까운 나사(C)까지 17.88 mm. 사실상 무간섭

### 가장 중요한 수정 2가지

1. **법선의 Z 성분을 2D 분석이 통째로 놓쳤다.** 실제 표면은 −0.20 ~ −0.64 만큼 아래를 향한다

2. **INDEX 행을 3 mm 내려야 한다.** Z=+12 에서는 pocket 상단 모서리가 나사 B boss 영역에
   접근해 holder 여유 11.5 mm / 나사 여유 2.39 mm 로 MARGINAL 이 된다.
   Z=+9 는 여유가 각각 13.5 mm / 4.20 mm 로 개선되고, 전면 기울기도 더 수직에 가깝다(§4)

## 15. 다음 CAD 수정 단계 (아직 실행하지 않음)

**선행 조건:** 사용자 소유 **사본 문서** (원본은 Adam Simon 소유, 수정 불가) + 라이선스 확인.

기술적 차단 요소는 **모두 해소되었다.** 남은 것은 문서 소유권과 설계 결정뿐이다.

| 단계 | 내용 |
|---|---|
| 1 | 신규 변수 블록 (`#finger_*`, `#hand_sign`, 행 Z, 호길이 offset) — 트리 최하단 append |
| 2 | INDEX row 용 기준 형상 (Z=+9), 각 버튼 위치에 **local normal 정렬** 평면 4개 |
| 3 | DOMINANT 3 + OPPOSITE 1 개구부 스케치 — mirror 구속 없이 좌우 분리 작성 |
| 4 | 개구부 REMOVE → 신규 backplate/리브 ADD(기존과 분리된 별도 body) → pocket REMOVE → 캡 NEW |
| 5 | MIDDLE row(Z=−6) 반복. **좌표 복제 금지** — 법선의 Z 성분이 −0.27 vs −0.64 로 크게 다름 |

각 단계 조회 → 확인 → 다음. 기존 엄지 버튼·조이스틱 피처는 일절 건드리지 않는다.
