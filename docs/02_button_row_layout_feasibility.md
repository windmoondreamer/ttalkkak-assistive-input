# 검지/중지 병렬 1열 배치 — 실현 가능성 검증 (READ ONLY)

- 검증 대상: 참조 이미지의 배치안 — 검지 4개(I1~I4), 중지 4개(M1~M4)를 각각 **독립된 병렬 1열**로,
  LEFT shell 3개 + RIGHT shell 1개가 사용자 관점에서 **하나의 연속된 row**로 느껴지게 배치
- 제약: fan / 삼각형 배열로 변경하지 않는다. 곡률로 인한 개별 3D 좌표·법선 차이는 허용
- 방법: 로프트 단면 스플라인을 clamped cubic으로 재구성해 **호길이 · 접선각** 계산
- 조회일 2026-08-18 / **CAD 수정 0건**
- 재현: `python scripts/section_arc.py Joystick_part_2 Joystick_part_3`

## 0. 결론 요약

| 검증 항목 | 판정 |
|---|---|
| 세로 공간 (2열 배치) | **가능** — 여유 충분 |
| 둘레 공간 (4개 감싸기) | **가능** — 필요 41mm / 전체 둘레 158.6mm (26%) |
| 3개를 하나의 평평한 그룹으로 | **가능** — 30.0mm 필요, 전면 ±20° 구간이 정확히 30mm |
| 4번째 버튼이 코너를 도는 것 | **불가피** — 그러나 참조 이미지와 일치 |
| **LEFT 3 + RIGHT 1 분할** | **현재 분할면 위치와 충돌 — 결정 필요** ← 유일한 blocking |

**병렬 1열 구조 자체는 실현 가능하다. fan 배열로 바꿀 필요 없다.**
막히는 지점은 단 하나: **원본 분할면이 그립 정중앙에 있어서, 그대로 두면 3+1이 아니라 2+2가 된다.**

## 2. 곡률 프로파일 — 어디까지가 "전면"인가

단면 part_2(검지 행 높이) 기준, 분할면에서 호길이만큼 이동했을 때의 접선각 변화:

| 분할면에서 호길이 | x | y | 접선각 | 판정 |
|---|---|---|---|---|
| 0 mm | 0.000 | 25.724 | 0.00° | 분할면 (전면 중앙) |
| 5 mm | 5.001 | 25.608 | −3.03° | 평면 |
| 10 mm | 9.955 | 25.123 | −8.69° | 평면 |
| **15 mm** | 14.845 | 23.964 | **−19.07°** | **전면 한계** |
| 20 mm | 19.222 | 21.640 | −39.08° | 코너 진입 |
| 25 mm | 22.173 | 17.670 | −66.32° | 코너 |
| 30 mm | 23.477 | 12.841 | −81.60° | 측면 |
| 35 mm | 23.859 | 7.858 | −88.71° | 측면 |

반대쪽 끝(P4)에서 되짚어도 거의 같다 (15mm→25.7°, 20mm→42.3°).
**즉 어느 쪽이 물리적 "앞면"이든 결론은 동일하다** — 앞/뒤 판별이 아직 UNKNOWN인 점이
이 검증의 결론에 영향을 주지 않는다.

### 사용 가능한 면적 정리 (part_2 기준)

| 영역 | 호길이 범위 | 전체 폭 |
|---|---|---|
| 접선각 ±20° 이내 (실질 평면) | 분할면 ±15 mm | **30.0 mm** |
| 접선각 ±40° 이내 (완만한 곡면) | 분할면 ±20 mm | 40.0 mm |
| 접선각 ±66° 이내 | 분할면 ±25 mm | 50.0 mm |

## 3. 버튼 열 소요 치수

원본 검증 치수(버튼 8mm, 갭 3mm) 상속 기준:

| 구성 | 계산 | 소요 호길이 |
|---|---|---|
| 버튼 3개 그룹 (I1–I3) | 3×8 + 2×3 | **30.0 mm** |
| 버튼 4개 연속 (I1–I4) | 4×8 + 3×3 | **41.0 mm** |
| 스위치 포켓 최소폭 | `#button_module_width` 6 + 2×0.2 | 6.4 mm (버튼 폭 하한) |

### 대조

- **3개 그룹 = 30.0 mm ≡ 전면 ±20° 구간 30.0 mm** → **정확히 들어맞는다.**
  I1·I2·I3를 하나의 평평한 연속 row로 만드는 것은 가능하다.
- **4개 연속 = 41.0 mm > 40.0 mm(±40° 구간)** → 4개를 모두 완만한 면에 두는 것은 불가능.
  **4번째 버튼은 반드시 코너를 돈다.**

> 이것은 참조 이미지와 모순되지 않는다. 이미지에서도 I4는 I1–I3 그룹과 간격을 두고
> **각진 면 위에** 그려져 있다. 즉 이미지 자체가 "3개 평면 그룹 + 1개 코너" 구조다.

버튼 폭을 줄여도 해결되지 않는다. 폭 7mm·갭 2.5mm로 줄여도 3개 그룹 26mm, 4개 연속 34mm이며
아래 4장의 분할면 문제는 오프셋 요구량이 17mm→15mm로 줄 뿐 그대로 남는다.

## 4. 핵심 충돌 — 3+1 분할 vs 정중앙 분할면

원본 분할면은 **그립 정중앙**(전면·후면 중심선)에 있다. 근거:

- `Mirror 1` 미러 평면 = `'JEC'` = `Joystick_side_profile` = `Screw_holes` 평면
- 로프트 단면이 x=0 → x=0 (절반만 생성)

이 상태에서 4개 열을 전면 중앙에 배치하면:

```
        LEFT shell          분할면          RIGHT shell
   ─────────────────────────── 0 ───────────────────────────
   I1(-20.5..-12.5)  I2(-9.5..-1.5) │ I3(+1.5..+9.5)  I4(+12.5..+20.5)
   ───────── 2개 ─────────────      │      ───────── 2개 ─────────
                    → 2 + 2  (스펙 위반)
```

3+1을 만들려면 분할면이 I3와 I4 **사이**에 와야 한다.
열을 전면 중앙에 두는 경우, 그 지점은 전면 중앙에서 **약 17 mm 옆**이다.

```
   I1(-20.5..-12.5) I2(-9.5..-1.5) I3(+1.5..+9.5) ┊ I4(+12.5..+20.5)
                                          분할면 필요 위치 ≈ +11 ~ +17
```

## 5. 선택지 비교

### A안 — 분할면 유지 + 열 전체를 좌측으로 시프트

버튼 3개가 모두 분할면 왼쪽에 오도록 열을 약 17mm 이동.

| 버튼 | 호길이 위치 | 중심 접선각 | 소속 |
|---|---|---|---|
| I1 | −30.0 … −22.0 | **≈ −70°** | LEFT |
| I2 | −19.0 … −11.0 | ≈ −19° | LEFT |
| I3 | −8.0 … 0.0 | ≈ −2° | LEFT |
| I4 | +3.0 … +11.0 | ≈ +5° | RIGHT |

- 원본 아키텍처 보존: **완전** (`Mirror 1` 그대로, append만)
- 오류 가능성: **낮음**
- 문제: I1이 측면으로 70° 돌아간다. I3·I4는 전면 중앙에 몰리고 I1만 멀리 떨어져
  **"연속된 row" 느낌이 깨진다.** 참조 이미지와 좌우가 뒤집힌 형태가 된다.
- 검지 도달성: I1이 그립 측면에 있어 손가락 끝이 아니라 중간 마디로 눌러야 할 수 있음

### B안 — 분할면을 약 17mm 옆으로 이동 (참조 이미지와 일치)

| 버튼 | 호길이 위치 | 중심 접선각 | 소속 |
|---|---|---|---|
| I1 | −15.0 … −7.0 | ≈ −13° | LEFT |
| I2 | −4.0 … +4.0 | ≈ 0° | LEFT |
| I3 | +7.0 … +15.0 | ≈ −13° | LEFT |
| I4 | +18.0 … +26.0 | ≈ −55° | RIGHT |

- 참조 이미지와 **일치**. I1–I3가 평평한 연속 row, I4만 코너
- 검지 도달성: **가장 좋음**
- 비용: **`Mirror 1` 폐기.** 두 쉘이 더 이상 서로의 미러가 아니게 된다.
  로프트가 절반만 만드는 구조(features 28–33)를 근본적으로 바꿔야 하며,
  이는 **트리 상류 수정**이라 "append only" 원칙에 위배된다.
- 부수 영향: 기존 엄지 버튼 개구부의 형상은 그대로지만 **소속 쉘이 재분배**된다
  (현재 분할면을 걸치는 BTN_2·BTN_5가 한쪽 쉘로 넘어가고, 대신 x=+11 버튼이 걸치게 됨)
- 나사 3개(`Screw_holes`)도 새 분할면으로 재배치 필요

### C안 — 분할면 유지 + 2+2 수용

- 원본 보존 최상, 위험 최소, 이미지와 가장 유사한 시각적 결과
- 그러나 **사용자 스펙(LEFT 3 + RIGHT 1) 위반**

### D안 — 버튼 폭 축소

- 스위치 포켓 6.4mm가 하한. 7mm 버튼까지 줄여도 분할면 오프셋 요구가 17→15mm로 줄 뿐
- **단독으로는 해결책이 아니다**

## 6. 세로 방향 (2열) 검증

| 항목 | 값 | 판정 |
|---|---|---|
| 나사 #2 (상단 경계) | side-plane y = 23.064 | 확정 |
| 나사 #3 (하단 경계) | side-plane y = −21.354 | 확정 |
| 방해물 없는 세로 band | **44.418 mm** | |
| 2열 소요 (버튼 8 + 갭 3 + 버튼 8) | **19.0 mm** | |
| 여유 | 25.4 mm | **충분** |
| 검지 행 권장 높이 | y ≈ +10 ~ +14 | part_2(y≈16.4)에 근접 |
| 중지 행 권장 높이 | y ≈ −4 ~ −8 | |
| 기존 엄지 backplate 하단 | front_y ≈ 25.5 | 검지 행 위쪽에 위치, 간섭 없음 |

**세로 방향은 병목이 아니다.** 행 피치를 14~18mm까지 넉넉히 잡아도 band 안에 들어간다.

단, 아래로 내려갈수록 단면이 좁아지고 곡률이 커진다:

| 단면 | 전면 ±20° 구간 폭 |
|---|---|
| part_2 (y ≈ 16.4, 검지) | 30.0 mm |
| part_3 (y = −50.266, 하단) | 약 20 mm (호길이 10mm에서 이미 28.5°) |

→ **중지 행은 검지 행보다 평평한 면이 좁다.** 중지 행을 너무 아래로 내리면
3개 그룹(30mm)이 ±20° 안에 들어가지 못한다. 중지 행은 y ≈ −4 ~ −8 이내를 권장한다.
(part_2와 part_3 사이 보간 기준. 정확한 값은 3D 확인 필요.)

## 8. 결정 필요 사항 (사용자)

**필수 결정 1 — 분할면 처리 방식**

- A안: 분할면 유지, 열을 좌측 시프트 → CAD 안전, 배치 타협 (I1이 70° 기울어짐)
- B안: 분할면 약 17mm 이동 → 이미지대로, 그러나 `Mirror 1` 폐기 + 상류 수정
- C안: 2+2 수용 → 스펙 변경

> 이 결정 없이는 신규 버튼의 위치를 확정할 수 없다.
> A안과 B안은 CAD 작업 범위가 근본적으로 다르다 (append only vs 상류 재설계).

**필수 결정 2 — 왼손용 / 오른손용**
어느 쪽 쉘이 손가락 끝이 닿는 면인지가 결정되어야 I1~I4 순서를 확정할 수 있다.

**필수 결정 3 — 행 높이**
검지 행 y ≈ +10~+14, 중지 행 y ≈ −4~−8 범위 안에서 실제 손 치수 기준 확정 필요.

## 9. 아직 확인되지 않은 사항

- 단면 4개의 정확한 그립 높이 — `Joystick_side_profile` 자취선 매칭으로 **추정**한 값
- 그립의 앞/뒤 판별 (P0가 전면인지 P4가 전면인지) — 결론에는 영향 없음(2장 참조)
- 내부 여유: 스위치 포켓(6.4mm) + 리브(10mm)가 들어갈 내부 공간 — **massproperties/bodydetails 401**
- 나사 보스의 실제 3D 점유 부피
- 배선 경로
- 실제 손가락 도달 범위 (사용자 손 치수 미확보)
- 중지 행 하한 높이의 정확한 값 (part_2↔part_3 보간에 의존)
