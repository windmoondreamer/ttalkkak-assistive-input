## 1. 직접 90° 검증 (실제 외피면 기준)

파생 좌표 관계가 아니라 **하우징의 실제 외부 경사면 facet 집합**에 평면을 적합해 측정했다.

```
외피면 facet 74 개, 면적 5782.65 mm2, 정점 222
최소자승 적합 법선 = (0.000000000, 0.000000000, 1.000000000)
평면 residual     : max 0.000e+00 mm,  rms 0.000e+00 mm

angle(GRIP_NEUTRAL_AXIS, 외피면 법선) = 0.000000000 deg
angle(GRIP_NEUTRAL_AXIS, 외피면)      = 90.000000000 deg     <-- 수용조건 90.000
판정 PASS  (오차 0.00e+00 deg)
```

같은 면을 월드 기준으로 재측정:

```
angle(외피면 법선, 월드 수직)  = 20.000000000 deg
angle(외피면, 월드 수평)       = 20.000000000 deg
angle(하우징 밑면, 외피면)     = 19.999999195 deg   (밑면=월드수평, 외피=20도 -> 차 20도가 맞다)
외피면 Z = -61.878506 (착좌 평면 +6.000),  크기 X[-58,58] Y[-30.73,85.27]
```

`GRIP_NEUTRAL_AXIS` 는 소켓 보어 축(= 그립 Part Studio +Z, `docs/00` 에서 +Z 편차 0.000000°로 실측)이다.

### 2.3 요구 저널 길이

**축1 — 캐리어 고정 / 링 회전.** 베어링 외륜 = 캐리어, 내륜 = 샤프트(링에 고정)

```
링 바깥면        |u| = 26.00
베어링 안쪽면    |u| = 26.50      <- 숄더 신설 위치
베어링 바깥면    |u| = 31.50
매끈 저널 구간   26.00 ~ 31.50 = 5.50 mm
런아웃/필렛 회피 +0.5
==> 사용 가능 매끈 Ø5 저널 길이 = 6.0 mm
```

**축2 — 링 회전 / 허브 회전.** 베어링 외륜 = 링, 내륜 = 샤프트(허브에 고정)

```
허브 노즈 끝면   |v| = 29.50   (Ø7.0 로 수정 후 내륜에만 접촉)
베어링          |v| = 29.50 ~ 34.50
==> 사용 가능 매끈 Ø5 저널 길이 = 5.5 mm
```

**총장 (머리 제외)**

| 축 | 저널 | 앵커 | 최소 총장 |
|---|---:|---:|---:|
| 축1 | 6.0 mm | 10.0 mm (D2 수정 후) | **16.0 mm** |
| 축2 | 5.5 mm | 11.3 mm (실측) | **16.8 mm** |

**후보 형태** (구매·확정하지 않음)

1. **Ø5 h7 매끈 다월 + 압입/접착** — 저널 품질 최상, 분해가 번거롭다
2. **숄더 볼트 Ø5 숄더 / M4 나사** — 숄더 길이 6 mm(축1) / 6 mm(축2) 규격품 존재.
   앵커가 M4 로 작아지므로 링/허브 탭을 M4 로 변경해야 한다
3. **부분나사 M5 (DIN 931 계열)** — 매끈 shank 를 저널로 쓴다.
   M5×20 이면 shank 약 8 mm 로 6.0/5.5 요구를 만족. **가장 조달이 쉽다**

셋 중 무엇을 쓰든 **베어링 ID 구간에는 나사산이 절대 들어가면 안 된다.**

## 3. 하우징 서비스성 — 분할 제안

### 3.1 분할면

**경사 외피와 평행한 파팅** (그립 프레임에서 상수 Z → 월드에서 20° 경사)

```
파팅면        grip Z = -78.5228   (착좌 평면 -10.644 = well 바닥)
상부 경사 셸   Z -78.523 ~ -61.879,  높이 16.644 mm
              안쪽 Ø98.91 (well) ~ 바깥 116 각,  벽 두께 8.55 mm (변 중앙)
하부 섀시      Z -78.523 아래 전부 — 공동 / 캐리어 포켓 / 바닥 / 짐벌 볼트 패턴
```

- **20° 외피 전체가 상부 셸에 있다** → 인체공학 면이 한 부품에 통째로 유지된다
- **피벗 위치 불변**, `HAND_REF` 두 높이 **불변**
- 상부 셸은 외피를 베드에 붙여 출력 → 손목 닿는 면에 계단이 없다

### 3.2 등록(registration)

- **스피곳 Ø96.0 × 3.0 mm**, 여유 0.15 mm/side. 셸 하단에서 섀시 카운터보어로 내려간다
  - r = 48.0 은 그립 스윕 반경 46.9 와 well 49.455 사이라 양쪽 모두 안전하다
  - (대안: 셸이 섀시 외벽을 감싸는 **외측 rabbet** — 내부 여유를 아예 안 쓴다)
- **M3 × 6**, 볼트원 r = 53.0 (well 49.5 와 외곽 58 사이). 섀시에 열간 인서트

### 3.3 캐리어 강성 개선

현재 캐리어는 바닥 M3 2개로만 고정된다. 모멘트를 나사 2개가 받는 구조다.

- 섀시에 **3면 포켓**(양 v 벽 + 바깥 u 벽)을 파서 캐리어를 끼운다 → 하중이 벽으로 간다
- **측면 조립 개구부 2개를 삭제한다.** 분할 후에는 캐리어를 위에서 넣을 수 있으므로
  (캐리어 바깥 모서리 r = 37.6 < 공동 46.76) 측면 개구가 필요 없다 → 측벽 연속성 회복

### 3.4 서비스 절차

```
1. M3 x6 풀기 -> 상부 경사 셸을 그립축(+Z) 방향으로 그대로 들어낸다
2. 공동이 완전히 열린다: 스프링 / 홀 PCB / 마그넷 / 배선 전부 접근 가능
3. 캐리어당 M3 x2 풀기 -> 캐리어를 베어링째 위로 들어낸다
4. HUB+RING 조립체를 위로 인출  (공동 Ø93.52 > 링 최대폭 74.0 -> 통과)
5. 축2 샤프트를 빼면 HUB 와 RING 분리
6. 역순 조립
```

인쇄 하우징을 파괴하지 않고 6개 항목(베어링/링/허브/스프링/홀/마그넷·배선) 전부 접근된다.

## 5. 주행 여유 — 각 경우에 무엇을 바꿔야 하나

`a1 = 33` (D2 수정안) 기준 실측:

| travel | 캐리어존 z_min | 필요 p | 현재 18.5 로 가능? | ringSweep | 필요 STACK_H |
|---:|---:|---:|---|---:|---:|
| **±10°** | −6.394 | **18.47** | **예** | 8.26 | 39.99 |
| ±12° | −7.721 | **19.80** | 아니오 → p = 19.8 | 9.89 | 42.75 |
| ±15° | −9.738 | **21.81** | 아니오 → p = 21.9 | 12.31 | 47.00 |

**각 경우에 바꿔야 하는 것**

| travel | 변경 사항 |
|---|---|
| ±10° | 없음. 현재 값 그대로 |
| ±12° | `#gimbal_travel` 12, `#pivot_depth` 19.8. **`STACK_H` 41.0 → 42.8 이상** |
| ±15° | `#gimbal_travel` 15, `#pivot_depth` 21.9. **`STACK_H` → 47.0 이상**, `HOUSE_HALF` 58 → 60 (wellR 51.44 → ⌀102.9, 116 각에 벽 6.6 mm 밖에 안 남는다) |

> **`STACK_H` 가 현재 41.0 mm 상수라 ±12° 이상에서 하우징 바닥이 뚫린다.**
> `STACK_H = (p + hBoss + ringSweep + CLR)·cos20° + HOUSE_FLR` 로 파라미터화해야 한다.
> 이것이 "미래 평가를 불필요하게 막지 않게" 하려면 반드시 고쳐야 할 항목이다.

높이 영향: ±12° 는 HAND_REF 를 약 +1.8 mm, ±15° 는 약 +6.0 mm 올린다 (베이스 기준).
