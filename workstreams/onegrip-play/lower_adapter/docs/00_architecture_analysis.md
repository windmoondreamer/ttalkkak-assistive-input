## 6. 권장 결합 방식

```
평면 착좌(하중) + 보스 포켓(전단/회전키) + post 복제(정밀 위치) + 클램프 링(수직 유지)
```

| 요소 | 역할 | 근거 |
|---|---|---|
| **평면 착좌면** (Z=−67.8785 대응) | 수직 하중 | 5017.5 mm² 평면 1개. 원본의 좁은 접촉(≈330 mm²)보다 훨씬 강함 |
| **보스 포켓** 31.0×35.5, 깊이 6.2 | 전단 + 회전키 + **쉘 벌어짐 억제** | 착좌면 바로 아래라 전단에 유리. 180° 오조립 2.546 mm 로 거부 |
| **post 복제** 20.272×25.272 | 정밀 위치 + 케이블 덕트 | 원본이 공차 관리한 면. 여유 X 0.40 / Y 0.20 mm/side |
| **클램프 링** (2분할) | 수직 이탈 방지 | 플랜지 립 오버행 Z=−64.0 에서 **5.93~10.18 mm** 확보 |

- post 높이 = 포켓 바닥에서 **20.8 mm** (보어 내 물림 20.6 mm, 원본과 동일)
- post 는 **중공(chimney)** 으로 만들어 케이블을 통과시킨다. 벽 4 mm → 내부 12.3×17.3 mm
  (원본 채널 10.136×12.636 보다 넉넉)
- post 밑동에 큰 필렛. **전단은 포켓이 받고 post 는 위치만 잡게 한다** (수직 프린트 층간 약점 회피)
- 상체는 **일절 가공하지 않는다.** 기존 나사 3개도 건드리지 않는다

기존 나사를 재사용하지 않는 이유: 셋 다 플랜지면보다 46 mm 이상 위에 있어, 거기까지
올라가는 크래들 팔은 손과 간섭한다. 대신 위 4요소로 4자유도(횡/종/수직/회전)를 모두 구속한다.

## 7. 권장 모듈 분할

```
[ OneGrip 상체 ]  <- 무수정
        |
[ A. Grip Cradle ]      각도 무관 / 정밀 피처 전부 여기 / 1회 제작 후 영구 재사용
        |  (평면 볼트 조인트, 4xM3)
[ B. Tilt Wedge ]       15/20/25/30 deg / 정밀 피처 0 / 각도 실험 시 이것만 재출력
        |
[ 수평 인터페이스 = 고정 스펙 ]  <- 미래 짐벌과의 계약
        |
[ 미래 X/Y 짐벌 ]

[ C. Flange Clamp Ring x2 ]  각도 무관
```

**분리(A+B 별도)를 권장한다.** 이유:

1. 각도를 바꿀 때 **정밀 피처(post·포켓·착좌면)를 다시 만들지 않는다.** 재출력되는 B 에는
   볼트 패턴 2개와 케이블 보어밖에 없어 그립 fit 이 깨질 위험이 0이다
2. 각 부품이 **자기 임계면을 베드에 붙여** 출력된다. A 는 착좌면 아래로, B 는 수평면 아래로
3. 조인트 위치가 좋다. 최대 모멘트는 post/소켓에 걸리지, 이 볼트 평면이 아니다.
   ⌀60 mm 볼트원의 4×M3 이면 충분하다
4. 클램프 링과 짐벌 인터페이스가 각도와 무관해져 재사용된다

**트레이드오프:** 조인트 1개, 높이 +4~5 mm, 나사 4개가 늘고 강성이 약간 떨어진다.
각도가 확정된 뒤 최종본에서는 A+B 를 하나로 합치면 된다.

**모듈 C(짐벌 인터페이스)는 지금 별도 부품으로 만들지 않기를 권한다.** 짐벌이 아직 없어
패턴을 확정할 수 없고, 판을 하나 더 끼우면 레버만 길어진다. 대신 **B 밑면의 평면 + 볼트 패턴을
지금 스펙으로 동결**하고, 나중에 짐벌 패턴이 다르면 그때 어댑터 판을 추가한다.

**웨지 경사면 주의:** 웨지는 두 면이 평행하지 않아 어느 쪽을 베드에 붙여도 반대면에 계단이
생긴다. → 경사면에 **3점 접촉 패드**를 세워 전면 접촉을 피하면 계단 영향이 사라진다.

## 12. 부록 A — 경사 기하 요구사항 확정 (2026-08-20 추가)

```

LOCAL_Z      = grip +Z  (= 중심축)
```

| **TOP → −Y** (내리막 = −Y, 엄지 패널이 오르막) | 41.22° | **21.22°** (거의 위를 봄) |
| TOP → +Y (내리막 = +Y, 엄지 패널이 내리막) | 41.22° | 61.22° (옆을 봄) |

"엄지는 위쪽으로" = **TOP → −Y**. 스케치에서도 로드가 내리막(좌)으로 기울고 엄지 패널이
오르막(봉우리, 우)을 향하는 배치와 일치한다.

```
확정: n = (0.000000, -0.342020, 0.939693)      # TOP -> -Y, theta = 20 deg
      회전 = RotX(+theta) about grip X through MOUNT_ORIGIN
```

### B.3 정정 — 손 방향과 경사 방향은 독립이다

§11 에서 "경사 방향은 좌/우手 결정과 묶여 있다" 고 적었으나 틀렸다.
`#hand_sign` 은 X=0 에 대한 미러 `M = diag(-1,1,1)` 이고, 경사는 **X 축 회전** `RotX(θ)` 다.

```
M · RotX(theta) · M^-1 = RotX(theta)
```

두 연산은 교환한다. **좌手 버전으로 미러해도 경사 방향은 그대로다.**
따라서 경사 방향 확정에 손 방향 결정을 기다릴 필요가 없다.

### B.5 이 방향의 대가 — 정적 편심

| 배치 | CG 수평편차 | 추정 전도 모멘트 (150 g 가정) |
|---|---:|---:|
| 원본 수직 | −26.817 mm | 4,020 g·mm |
| **확정 (TOP → −Y, 20°)** | **−45.596 mm** | **6,840 g·mm (원본의 1.70배)** |
| (반대 방향 참고) | −4.804 mm | 720 g·mm |

짐벌 피벗을 축 아래 `L` 만큼 내렸을 때의 수평편차 = `[rot(CG−O)]_Y + L·n_Y`:

- **TOP → −Y**: `−45.596 − 0.342·L` — L 을 늘릴수록 악화. **0 이 되는 L 이 없다**
- (참고) TOP → +Y: `−4.804 + 0.342·L` — `L = 14.05 mm` 에서 정확히 0

**따라서 이 방향에서는 기하학만으로 균형을 맞출 수 없다.** 셀프센터링 스틱의 중립점이
−Y 로 치우치므로, 짐벌 설계 단계에서 다음 중 하나로 처리해야 한다:

1. 센터링 스프링 프리로드 비대칭 조정
2. 어댑터/웨지 내부 +Y 측 카운터웨이트
3. 홀센서 중립 오프셋을 펌웨어에서 보정 (기계적 편심은 남음)

원본도 이미 4,020 g·mm 로 동작하므로 치명적이지는 않으나, **증가분 70 % 는 짐벌 미결
항목으로 명시 이월한다.**
