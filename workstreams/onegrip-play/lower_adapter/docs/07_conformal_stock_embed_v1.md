## 5. §20 패키징 변형 비교

무릎면 파라미터(및 COMPACT 만 외피 규칙)를 바꿔 3안을 실제로 생성해 측정했다.
**스톡 짐벌은 세 안에서 완전히 동일하다.**

| 변형 | 하우징 W × L × H | 접지 W × L | 접지면적 | 하우징 부피 | (참고) PLA 100% | B | D |
|---|---|---|---:|---:|---:|---:|---:|
| **COMPACT** | 128.6 × 170.6 × 139.9 | 128.6 × 85.3 | 2,920 mm² | **322,198 mm³** | 400 g | 161.02 | **0** |
| **BALANCED** ★ | 128.6 × 170.6 × 139.9 | 128.6 × 97.3 | 3,176 mm² | 495,615 mm³ | 615 g | 161.02 | **0** |
| **FULLY_ENCLOSED** | 128.6 × 170.6 × 139.9 | 128.6 × 170.6 | 5,964 mm² | 537,090 mm³ | 666 g | 161.02 | **0** |

- **COMPACT** — 외피를 국소창 규칙(허리 허용)으로 만들고 무릎 42° @ Y6.
  중간부가 76~82 mm 로 잘록해져 부피가 **−35%**.
  대신 허리에서 덱 쪽으로 **수평 단(최대 13 mm)** 이 생겨 어느 방향으로 인쇄하든
  서포트가 필요하다.
- **BALANCED (채택)** — 외피 단조 테이퍼 + 무릎 34° @ Y18.
  외부 수평 단이 스커트 플레어 한 곳뿐이고, 벽이 두꺼운 중간부는 **인필로 비는 영역**이라
  실제 소요 재료 차이는 부피 차이보다 훨씬 작다. 강성/인쇄성이 가장 좋다.
- **FULLY_ENCLOSED** — 무릎 절단 없음. 접지면적이 가장 크고(5,964 mm²) 외관이 가장
  깔끔하지만 +Y 하부에 스톡이 전혀 없는 쐐기를 41,475 mm³ 더 채운다.

**권고: BALANCED.** 세 안의 A/B/D/H 가 모두 동일하므로 선택 기준은
`부피 ↔ 접지 안정성 ↔ 인쇄성` 뿐이고, BALANCED 가 그 셋의 균형점이다.
총 인쇄 시간을 더 줄여야 하면 `#knee_angle` / `#knee_y` 만 바꿔 COMPACT 쪽으로
이동할 수 있다 (외피 규칙 변경은 `gen_conformal_fs.py` 한 줄).

## 7. 중간 결함 4건과 수정

이번 작업의 실패는 전부 **불리언 위상** 문제였다. `GET /features` 가 429
(Retry-After 20,887 s) 라 오류 메시지를 직접 못 읽어, 두 가지 진단 수단을 새로 만들었다.

1. **`#trace_steps` 단계 제한 변수** — 피처가 N 단계만 실행하고 반환하게 해서
   POST 응답의 OK/ERROR 와 `/parts` 개수만으로 실패 지점을 이분 탐색한다.
2. **FeatureScript 평가 엔드포인트** (`POST .../featurescript`) —
   **429 를 받지 않는다.** `try/catch` + `print` 로 실제 오류 메시지를 얻었다.
   단 **최상위 선언을 허용하지 않는다** (단일 함수 표현식만) — `import` / `enum` /
   `export` / 최상위 `function` 전부 파서 오류.

| # | 증상 | 원인 | 수정 |
|---|---|---|---|
| 1 | HOUSING 전체 ERROR | `BaseFill` enum 을 지우면서 §9 블록이 **반쯤 남아** 깨진 코드가 됨 | 블록 완전 제거. 애초에 "solid base" 는 캐리어 하방 탈착과 양립 불가라 변형을 무릎면 파라미터로 옮겼다 |
| 2 | 공동 밴드 2 절삭 시 `BOOLEAN_NON_MANIFOLD_RESULT` | 밴드를 **하나씩** 빼면 인접 공동 경계가 맞닿는다 | 공동 밴드 + 캐리어 개구를 **먼저 하나로 UNION 한 뒤 한 번에** SUBTRACT |
| 3 | 여전히 밴드 2 에서 non-manifold | 외피를 "위쪽 밴드 최대"로만 잡아서, 아래 밴드가 −Y 로 더 튀어나온 구간의 Z 경계에서 **두께 0 칼날 모서리** 발생 (밴드 2 의 y0 = −25 가 한 밴드 위 외피면 y0 = −25 와 정확히 동일, Z = −126) | 외피 규칙을 **한 밴드 아래까지 포함**(`cav[i-1:]`)으로 변경 |
| 4 | 최상단 밴드 절삭에서 non-manifold | 덱 개구부를 테이퍼(92→82)로 만든 마지막 단 | 최상단 두 밴드를 **병합**해 곧은 개구부(92 × 89)로 단순화. thin-deck 안의 90.8 × 87.5 와 같은 급 |

### 검증 도구 자체의 결함 1건

첫 검증에서 "캐리어 ↔ 하우징 28 복셀" / "인출 t=0 차단" 이 나왔다. **오탐이었다.**

`crossings=5, t=[3.043, 3.043, 11.043, 11.043, 18.0]` 로 중복을 확인했다.
`inside_mesh` 에 **교차점 중복 제거**를 추가해 해소 → 0 복셀.

## 8. 전장 / 배선

`docs/06 §4` 의 실측을 그대로 쓴다. 스톡 CAD 는 전장 포켓을 모델링하지 않았고
(전장 표본의 81.1% 가 Base 솔리드 내부), USB 셸이 Base 밑면 아래 2.850 mm 로 나온다.

- 꼬리 체인(내부 X ±16, 외피 X ±21, Y −77 까지)이 Arduino + USB 를 **하우징 안에** 담는다.
- **USB / 케이블 포트**: −Y 벽에 폭 16.0 mm, Z −155.81 … −138.25 관통.
- 굽힘 반경 / 스트레인 릴리프는 포트 바깥(하우징 밖)에서 처리한다 → 불필요한 큰 공동 없음.
- 캐리어의 꼬리 슬롯은 −Y 로 완전 관통이라 **아래에서 전장에 직접 접근**할 수 있다.

전부 **provisional** 이다 (커넥터/케이블 형상이 CAD 에 없음).

## 9. 미해결 / 확인 필요

1. **`#usb_clearance` 6.0 mm 가정** — 실제 마이크로 USB 플러그 몸체로 검증 필요.
   0 으로 낮추면 B 가 155.02 mm 가 된다.
2. **M3×22 / M3 인서트 규격 provisional** — 실물 하드웨어 검증 전.
   Base 밑면 카운터보어 깊이와 ⌀3.000 블라인드의 실제 체결 방식(셀프탭 여부)도 미확인.
3. **`GET /features` 429** — 재생성 상태를 직접 못 읽었다. 간접 확인:
   두 피처 POST `featureStatus = OK`, `/parts` = solid 2 / wire 0,
   `massproperties` 부피가 메시 적분과 일치, 26개 기하 게이트 전부 PASS.
4. **`#trace_steps` 진단 변수가 트리에 남아 있다** (값 0 = 전체 실행).
   유용해서 남겼으나 최종 정리 시 제거 여부 결정 필요.
5. **인쇄 방향 / 서포트 미평가.** BALANCED 는 외부 수평 단이 스커트 플레어뿐이지만,
   덱 밑면 둘레 턱과 캐리어 착좌 환형은 여전히 하향면이다. 45도 챔퍼가 v2 항목.
6. **꼬리가 하우징 −Y 로 길다** — 전체 길이 170.6 mm 중 42 mm 가 전장 꼬리다.
   MCU 재배치는 §24 로 금지되어 있으므로 이번 범위 밖.

## 부록 — FeatureScript / API 교훈 (이번에 추가)

- **`POST .../featurescript` 평가 엔드포인트는 `GET /features` 와 다른 버킷이다.**
  429 상황에서 유일하게 오류 메시지를 얻는 경로다. 단 **최상위 선언 불가** —
  `import` / `enum` / `export` / 최상위 `function` 전부 파서 오류이고,
  단일 `function(context is Context, queries is map){...}` 표현식만 받는다.
  `queries` 는 **배열이 아니라 map** 이어야 한다 (`{}`).
- 밴드 스택을 **하나씩 빼면** 인접 공동 경계에서 `BOOLEAN_NON_MANIFOLD_RESULT` 가 난다.
  → **도구를 먼저 UNION 한 뒤 한 번에 SUBTRACT** 하는 것이 기본형이다.
- 외피를 "위쪽 최대"로만 만들면 아래 밴드가 튀어나온 구간에서 **두께 0 칼날 모서리**가
  생긴다. 외피 규칙은 **인접 밴드(위·아래)를 모두 포함**해야 한다.
- 서로 떨어진 body 를 `opBoolean` UNION 하면 분리 결과가 된다.
  꼬리 체인처럼 별도 체인을 붙일 때는 **본체와 확실히 겹치도록** 범위를 잡아야 한다.
- **레이 패리티 내부 판정은 교차점 중복 제거가 필수다.** 점이 공유 모서리
  (원기둥 접선 등) 에 정확히 놓이면 같은 t 가 2번 잡혀 판정이 뒤집힌다.
