## 1. 핵심 기하 — 손목면은 20° 평면 위에 놓을 수 없다

20° 평면은 −Y 로 1 mm 갈 때마다 **0.342 mm 씩 떨어진다.** 상부 외피를 그대로
85 mm 앞으로 늘리면 손목 자리가 필요보다 29 mm 낮아진다.

그래서 손목면은 **더 완만한 별도 평면**(`#wrist_pad_angle` = 7°)이고,
덱 평면 연장선 **위에 얹히는 쐐기**가 된다. 그 결과가 "앞쪽에서 완만하게 올라오는"
형상이다.

```
grip 좌표에서 패드 평면
  앵커 (Y = -20,      Z = -61.8785)   <- 덱 평면과 접함
  앞끝 (Y = -103.44,  Z = -42.61)     <- 덱보다 19.27 mm 위
  법선 (0, 0.2251, 0.9744)  ->  월드 수평과 7.0000 deg
```

조작 영역과는 부딪히지 않는다. ±10° 그립 스윕의 −Y 한계는 덱 평면에서
`grip Y = −10.51` 이고 위로 갈수록 −Y 로 물러난다. 쐐기의 최대 Y 는 −20 이므로
**어느 높이에서도 교차하지 않는다** (최소 여유 9.5 mm, 대부분 구간 45 mm 이상).

## 6. 모서리 라운드 — 부분 성공, 미적용 상태

요청 항목 7(사용자 접촉 모서리 라운드)은 **아직 적용되지 않았다.**

실측한 것:

| 시도 | 결과 |
|---|---|
| 패드 주변 구(R95) 안의 **모든 모서리** 일괄 필렛 | R6/4/3/2/1.5/1 **전부 `FILLET_FAILED`** (내부 얇은 벽까지 걸린다) |
| 패드 **상면에 접한 8개 모서리**만 일괄 필렛 | R8/6/4/3/2 **전부 실패** |
| 같은 8개를 **하나씩** 필렛 (R3) | 앞면 `y=-103` **OK**, 좌측면 `x=-43` **OK**, 우측면 `x=+43` **OK** |

원인: 8개 모서리를 한 루프로 걸면 코너 호와 앵커 크리즈(덱과 13° 밖에 안 벌어진다)
때문에 전체가 죽는다.

**적용할 수정 (코드는 이미 반영, 실행만 남음):** 8개를 개별 `try silent` 로 돌려
되는 것만 라운드한다. 그러면 손목이 실제로 닿는 앞면 + 양측면이 R3 로 부드러워지고,
코너 호와 앵커 크리즈는 그대로 남는다 (코너는 평면상 이미 R16, 앵커는 13° 완만한
크리즈라 손에 걸리지 않는다).

`#edge_fillet = 0` 이면 이 블록은 통째로 건너뛴다. 현재 값이 0 이다.

## 7. ⚠ 현재 상태 경고 — API 402 로 중단

작업 마지막에 Onshape API 가 **402 `API limit exceeded`** 로 막혔다.
읽기·쓰기 **모두** 불가이며 `Retry-After` 헤더도 없다.

### 마지막으로 **검증된** 상태

`ERGO_SHELL` 634,810 mm³ + `BOTTOM_CARRIER` 90,178 mm³, **28/28 PASS**.
이 지오메트리는 필렛이 없는 상태다.

### 그 이후 확인하지 못한 것

1. **마지막 Feature Studio 업로드가 컴파일되는지 확인 못 했다.**
   내용 POST 는 성공했고 `featurespecs` GET 에서 402 를 받았다.
   그 업로드는 §6 의 개별 `try silent` 필렛 루프를 담고 있다.
2. `#edge_fillet` 은 진단 중 **0 mm** 로 되돌려 둔 값 그대로다
   (`3 mm` 로 바꾸려던 요청이 402 로 실패).
3. **결과 버전을 만들지 못했다.**

`#edge_fillet = 0` 이므로 필렛 블록은 실행되지 않는다.
→ **새 FS 가 컴파일만 되면 형상은 검증된 634,810 mm³ 와 동일해야 한다.**
컴파일이 안 되면 두 피처가 ERROR 로 뜨고 body 가 사라진다.

### 쿼터 회복 후 복구 순서

```bash
python lower_adapter/scripts/run_ergo.py upload    # 컴파일 확인 (featureSpecs 1개)
python lower_adapter/scripts/run_ergo.py parts     # solid 2 / shell 634,810 확인
python lower_adapter/scripts/run_ergo.py setvar edge_fillet "3 mm"
python lower_adapter/scripts/verify_ergo.py --fetch
# 통과하면 버전 생성: ERGO_SHELL_W2_V1
```

컴파일이 깨져 있으면 `#edge_fillet` 을 0 으로 둔 채 §6 의 필렛 블록만 제거하고
재업로드하면 검증된 형상으로 돌아간다.

## 부록 — 이번에 추가된 교훈

- **`getVariable` 은 트리에서 그 피처보다 **앞에** 선언된 변수만 본다.**
  변수를 나중에 append 하면 피처가 ERROR 로 죽는다. 피처를 지우고 변수를 앞으로
  보낸 뒤 다시 붙여야 한다.
- **`opFillet` 은 여러 모서리를 한 번에 걸면 하나만 실패해도 전부 죽는다.**
  개별 `try silent` 루프가 훨씬 견고하다.
- **`|cross(v1-v0, v2-v0)|` 은 삼각형 넓이의 2배다.** 면적 보고 시 반드시 나눠야 하고,
  법선 정규화는 원래 크기로 해야 한다 (둘을 섞으면 접지 면적이 9배로 나온다).
- **평면 절단 도구는 대상 body 를 좁혀야 한다.** 손목 패드 평면을 셸 전체에 걸었더니
  +Y 쪽에서 그 평면이 덱보다 20.8 mm 아래로 내려가 **20° 기준면 상부를 통째로**
  잘라냈다. 최대 높이가 139.9 → 118.4 로 줄어 있었다.
- Onshape API 는 429(rate limit) 와 별개로 **402 `API limit exceeded`** 를 낸다.
  402 는 읽기까지 전부 막히고 `Retry-After` 도 없다.
