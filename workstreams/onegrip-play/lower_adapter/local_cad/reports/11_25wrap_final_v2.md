# 25° 랩 스커트 — 접합부 폭 정합 최종 (V2)

`ERGO_HOUSING_25_WRAP_FINAL` (팔받침 폭 86 mm) 에서 **하우징 ↔ 팔받침 접합부의
폭 단차만** 제거한 버전이다. 경사각 25° / 랩 스커트 / 동결 코어 / 캐리어 인터페이스는
전부 그대로다. Onshape API 호출 0건.

이전 버전 `ERGO_HOUSING_25_WRAP_FINAL` 은 **삭제하지 않고 보존**했다.

---

## 1. 무엇이 문제였나

TOP 실루엣이 접합부에서 계단처럼 튀었다 (6 mm 간격 실측):

```
Y=-86 : 122.27  →(+5.74)  Y=-80 : 128.01  →(+5.27)  Y=-74 : 133.28  →(+0.32)  Y=-68 : 133.60
```

원인은 폭 스케줄이었다. 경사면 폭을 앞끝 0.68 → 1.00 으로 보간하면서
끝점을 **Y = −15 (하우징 뒤끝)** 로 잡았다. 그래서 하우징 앞면(Y = −81.8)에서는
아직 0.91 배 = **121.8 mm** 인데 하우징은 이미 **133.60 mm** 라, 두 몸이 만나는
바로 그 자리에서 11.8 mm 가 어긋났다.

## 2. 수정

폭 스케줄의 끝점을 **하우징 앞면 `y_front_body`** 로 다시 걸었다.
경사면이 하우징에 닿는 순간 폭이 정확히 1.00 (= 133.60 mm) 이 된다.

```python
f = (yk - y_tip) / (y_front_body - y_tip)
wfrac.append(0.68 + (1.00 - 0.68) * min(1.0, max(0.0, f)))
```

형상 변경은 **이 한 곳뿐**이다. 경사각·스커트·덱 캡·필렛·keep-out 은 무수정.

### 결과 (6 mm 간격 실측)

```
… 131.82 →(+1.34) 133.05 →(+1.22) 133.60 →(+0.00) 133.60 …
접합 구간 최대 증분  1.34 mm / 6 mm
```

단차가 사라지고 **Y = −80 에서 133.60 에 도달해 그대로 이어진다.**
TOP 렌더에서 옆선이 끊기지 않는 것을 확인했다.

> 자동 검사가 보고한 "최대 증분 5.15 mm" 는 Y = +4 의 **하우징 뒤끝**이고
> 팔받침 접합부와 무관하다.

## 3. STL watertight — tolerance 0.030 으로 변경

기본 tol 0.015 에서 **경계 모서리 6개**가 나왔다. 위치를 찍어보니 전부
**Z = −61.8785 (덱 평면 정확히), Y = −18.00, X ≈ ±40** 이다.

원인은 경사면 상단을 `min(ramp_z, DECK)` 로 **덱에 정확히 맞춰** 자른 것이다.
그 면이 동결 코어 상면과 **완전 동일 평면**이 되고, 폭을 넓히면서 그 구간이
커지자 두 면의 tessellation 이 격자에서 갈라졌다.

tolerance 별 실측:

| tol / ang | 삼각형 | 경계 | 비다양체 | watertight |
|---|---|---|---|---|
| 0.008 / 0.04 | 86,268 | 6 | 0 | False |
| 0.010 / 0.05 | 65,213 | 172 | 1 | False |
| 0.015 / 0.08 | 38,770 | 6 | 0 | False |
| 0.020 / 0.10 | 30,392 | 6 | 0 | False |
| **0.030 / 0.15** | **20,016** | **0** | **0** | **True** |
| 0.050 / 0.20 | 15,452 | 0 | 0 | True |

**0.030 채택.** 형상은 손대지 않았다. 0.03 mm chord 편차는 FDM 레이어
(0.1~0.2 mm) 보다 훨씬 작아 제조 품질에 영향이 없다.

## 7. 이번 단계에서 고친 것

1. **폭 스케줄 앵커 오류.** 끝점을 하우징 뒤끝(Y = −15)에 잡아 접합부에서
   11.8 mm 단차. `y_front_body` 로 재앵커.
2. **STL tolerance.** 덱 동일평면 이음매 때문에 tol ≤ 0.020 에서 경계 모서리 6개.
   형상 수정 없이 tol 0.030 채택.
3. **조립 프리뷰 파일명.** `ONEGRIP_FINAL_LOCAL_PREVIEW` 로 뭉개지던 것을
   base 이름에서 유도하도록 바꿔 V1/V2 파일이 서로 덮어쓰지 않게 했다.
