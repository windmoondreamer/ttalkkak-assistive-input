## 1. 분석 방법

메시 비교로는 국소화가 되지 않아(구간별로 닫힌 메시가 아님) **레이 패리티**를 사용했다.

1. Joystick_2 를 X 반전해 Joystick_1 과 같은 쪽에 놓는다
2. (Y, Z) 격자 2 mm 마다 +X 방향 레이를 한 번 쏜다
3. 교차점 패리티로 '재료 구간'을 구하고 두 쉘의 총 재료 길이를 비교
4. 셀당 부피차 = (길이차) × 2 mm × 2 mm

검증: 판정불가 레이 0개, 총합 **+1.325 cm³** (massproperties 기준 **+1.270 cm³**, 격자 2 mm 오차 4%).

## 2. Joystick_1 / Joystick_2 부피차 원인

### 2.1 부피차의 Z 분포

| Z 구간 | 부피차 (J2 − J1) | 해당 위치 |
|---|---|---|
| −30 … −20 | **+0.317** | 나사 C (Z −21.35) |
| −20 … −10 | **+0.101** | 나사 C 연장 |
| +20 … +30 | **+0.503** | 나사 B (Z 23.07) |
| +40 … +50 | **+0.410** | 나사 A (Z 45.98) |
| −80 … −70 | −0.020 | Pitch 결합부 |
| 그 외 전 구간 | \|차\| ≤ 0.01 | — |

**차이가 나사 3개 위치에만 집중된다.** 그 외 구간은 전부 0에 수렴한다.

### 2.2 나사부 단면 실측 — 원인 확정

나사 B 축(Y −14.45, Z 23.07) 주변을 반경 방향으로 스캔한 결과:

| 축에서 거리 | Joystick_1 재료 | Joystick_2 재료 | 해석 |
|---|---|---|---|
| \|dy\| ≥ 4.0 mm | 3.00 mm | 2.98 mm | 쉘 벽만 — **동일** |
| \|dy\| ≈ 3.0–3.5 mm | 24.4 mm | 24.4 mm | **보스 외곽은 양쪽 동일 (⌀7)** |
| \|dy\| = 1.5–3.0 mm | **7.00 mm** | 24.49 mm | J1 에 **카운터보어** |
| \|dy\| < 1.5 mm | **0.00 mm** | 14.49 mm | J1 관통, J2 는 10 mm 탭홀 |

나사 축을 그대로 관통시킨 결과:

| 나사 | Joystick_1 재료 | Joystick_2 재료 |
|---|---|---|
| A (Z 45.98) | **0.00 mm** | 12.56 mm |
| B (Z 23.07) | **0.00 mm** | 14.49 mm |
| C (Z −21.35) | **0.00 mm** | 9.59 mm |

### 2.3 결론

```
Joystick_1 = 나사 머리 쪽  : ⌀3.5 관통 clearance hole + 카운터보어  → 재료 제거 많음
Joystick_2 = 나사 체결 쪽  : ⌀2.7 탭홀 깊이 10 mm                  → 재료 제거 적음
```

보스 길이 24.49 mm 중 J2 에 남은 재료 14.49 mm → **탭홀 깊이 정확히 10.0 mm**.
`#screw_depth = 10 mm` 와 일치하고, M3×16 나사가 J1 관통부(약 6 mm) + J2 탭홀(10 mm)로
정확히 소진된다. **설계 의도대로다.**

피처 트리와도 일치한다. `Screw_holes`(#34)는 `Mirror 1`(#33) **이후**에 있고,
Extrude 18·19(ADD)로 양쪽에 보스를 세운 뒤 Extrude 20·21·22(REMOVE)로
한쪽에는 클리어런스·카운터보어를, 다른 쪽에는 탭홀을 판다.
**미러 이후에 의도적으로 만든 비대칭이다.**

### 2.4 분류

| 분류 | 부피차 | 비중 | 판정 |
|---|---|---|---|
| **screw / fastener 관련** | **+1.331 cm³** | **96.6%** | **의도된 설계. 정상** |
| pitch attachment 관련 | −0.045 cm³ | 3.4% | §3 참조 |
| thumb controls 관련 | 0 | 0% | 없음 |
| shell opening 관련 | 0 | 0% | 없음 (개구부는 완전 대칭) |
| construction artifact | ±0.11 mm 수준 | 무시 | 테셀레이션 노이즈 |
| 실제 비대칭 외형 | **0** | **0%** | **없음 — 외피는 완전 대칭** |
| 기타 | 0 | 0% | — |

합계 +1.331 − 0.045 = **+1.286 cm³** ≈ massproperties 실측 +1.270 cm³.

## 3. 잔여 비대칭 (Pitch 결합부)

나사가 아닌 유일한 실제 차이:

| 항목 | 값 |
|---|---|
| 위치 | Y 35 … 37, Z −70 … −72 (그립 **후방 최하단**) |
| 형태 | Joystick_1 에만 존재하는 X방향 두께 **5.00 mm** 형상 |
| 부피 | 약 **0.045 cm³** (전체 차이의 3.4%) |
| Pitch 탱 점유 구간(Z −74…−58) 내부 | **예** |
| 신규 INDEX row(Z +9)까지 거리 | **약 80 mm** |
| 신규 MIDDLE row(Z −6)까지 거리 | **약 65 mm** |

추정 원인: 피처 트리에서 grip↔Pitch 결합부를 **두 쉘에 대해 별도 체인**으로 만든다
(`Extrude 14 → Boolean 2 → Delete 1 → Boolean 3` / `Extrude 15 → Boolean 4 → Delete 2 → Boolean 5`).
미러가 아니라 각각 작성된 연산이므로 소폭 차이가 남을 수 있다.
**정확한 정체는 미확정**이나, 크기·위치 모두 신규 설계와 무관하다.

그 외 (Y 26…36, Z −65…−66)과 (Y 44, Z −57)에서 관측된 ±0.05 ~ 0.11 mm 차이는
테셀레이션 chord tolerance(0.15 mm) 이내로 **노이즈**다.

## 4. 신규 finger button 영역 대칭성

| 영역 | 부피차 | **최대 재료 길이차** | 차이 셀 수 |
|---|---|---|---|
| INDEX (Z +3 … +15) | +0.0001 cm³ | **0.10 mm** | 5 |
| MIDDLE (Z −12 … 0) | +0.0004 cm³ | **0.10 mm** | 1 |

최대 차이 0.10 mm 는 테셀레이션 chord tolerance(0.15 mm) **이하**다.
즉 측정 한계 내에서 **두 쉘은 신규 버튼 영역에서 완전한 미러**다.

- 외피 형상 대칭 ✔
- 내부 캐비티 대칭 ✔
- 벽 두께 대칭 ✔ (양쪽 2.98–3.01 mm)
- 이 영역에 나사 보스·엄지 구조·Pitch 결합부 **모두 없음** ✔

가장 가까운 비대칭 요소는 나사 B 보스(Z 20–26)로, INDEX row 상단(Z 13)에서 **7 mm 이상** 위다.
docs/04 에서 확인한 holder 여유 4.20 mm 는 이미 이 보스를 고려한 값이다.

## 5. `#hand_sign` 좌우 반전 방식 검토

**판정: 문제 없음.**

| 검토 항목 | 결과 |
|---|---|
| 신규 버튼 영역 좌우 대칭 | **완전 대칭** (§4) → 반전해도 동일한 형상 위에 앉는다 |
| 반전 시 DOMINANT 쉘 변경 | Joystick_2(탭홀 측) → Joystick_1(카운터보어 측) |
| 그 변경이 holder 여유에 미치는 영향 | **없음.** 보스 **외곽 ⌀7 은 양쪽 동일**하고, 카운터보어는 그 안쪽 재료만 더 파낸다. docs/04 의 나사 여유는 ⌀7 외곽 기준으로 계산했으므로 반전해도 값이 나빠지지 않는다 |
| 엄지 버튼·조이스틱 | 분할면 기준 대칭 배치 → 반전 영향 없음 |
| Pitch 결합부 비대칭(§3) | 손 방향과 무관한 기구 결합부. 영향 없음 |

**단, 반전 시 함께 결정할 사항이 하나 있다:**
나사 머리가 항상 같은 쪽(예: 사용자 기준 바깥쪽)에서 들어가게 하려면
`Screw_holes` 계열(Extrude 20·21·22)의 좌우도 함께 뒤집어야 한다.
이는 **상류 피처**이므로, 반전 버전을 만들 때 별도 결정이 필요하다.
초판(한쪽 손)에서는 해당 사항 없음.

## 6. HW504_B ×2 의 정체

**판정: 중복 인스턴스가 아니다. 서로 다른 두 body 다.**

| | 인스턴스 \<1> | 인스턴스 \<2> |
|---|---|---|
| **partId** | **JFH** | **JFD** |
| elementId | `c349d3fc572261fbfb95897f` (동일) | 동일 |
| configuration | default | default |
| 부피 | **1.461 cm³** | **0.767 cm³** |
| bbox X | −15.50 … 11.50 (27.0) | −8.50 … 8.50 (17.0) |
| bbox Y | −1.25 … 13.00 (14.25) | 1.00 … 20.00 (19.0) |
| bbox Z | −19.46 … 19.46 (38.9) | −9.10 … 3.90 (13.0) |
| 어셈블리 원점 | (−6.472, −40.201, 53.746) | (−6.477, −40.272, 53.800) |

### mate 연결

| mate 이름 | 참조 |
|---|---|
| `Joystick_module` | **\<1> (JFH)** 만 |
| `Small_joystick_attachment` | **\<2> (JFD)** 만 |
| `Joystick_inside_part` | \<1> 과 \<2> 둘 다 |

### 해석

`HW504_B` Part Studio 에 **solid body 가 2개**(JFH, JFD) 있고, 둘 다 이름이 `HW504_B` 다.
어셈블리는 이 둘을 각각 한 번씩 인스턴스화한다.

- **JFH (\<1>, 27 × 14.25 × 38.9 mm)** = 모듈 본체 / 고정부.
  `Joystick_module` mate 로 쉘에 고정된다
- **JFD (\<2>, 17 × 19 × 13 mm)** = 가동 스틱부.
  `Small_joystick_attachment` mate 로 스틱 캡과 연결된다

원점이 0.07 mm 차이나는 것은 **두 body 의 로컬 원점이 다르기 때문**이며,
같은 부품을 두 번 넣은 것이 아니다.

> **docs/00 §6 및 docs/04 §11 정정:**
> "HW504_B 가 2개인 이유 UNKNOWN / 중복 인스턴스로 보임" 이라고 적은 것은 **틀렸다.**
> 실제로는 **엄지 조이스틱 1개가 고정부 + 가동부 2 body 로 모델링된 것**이며 정상이다.
> 신규 설계에서 "조이스틱 2개"로 취급하면 안 된다.
