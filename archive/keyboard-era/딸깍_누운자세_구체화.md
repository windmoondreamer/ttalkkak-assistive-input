# 누운 자세 사용자 구체화 — Track A / Track B

작성 2026-08-08 · 자세 조건: **앙와위(천장 보는 자세)** 와 **상체 30~45° 거상** 두 가지
범위: 앉은 자세 한 손 사용자 + 누운 자세 사용자를 **하나의 코어로** 지원

> 의학적 서술은 일반적 진행 패턴에 기반한 것이며 개인차가 큽니다.
> 확신도 **중간** 이하로 표시했고, 수요자 검증 전에는 확정하지 마십시오.

---

## 1. 누운 자세가 공통으로 바꾸는 것 5가지

앉은 자세와 물리 조건이 다릅니다. 기기보다 **거치와 피드백**이 먼저 무너집니다.

### 1.1 중력 방향이 90° 바뀐다

앉은 자세에서는 중력이 기기를 책상에 눌러 고정해 줍니다.
누운 자세에서는 그 힘이 사라지고, 오히려 기기를 몸에서 굴러떨어뜨리는 방향으로 작용합니다.

→ v1 §4에서 "자중 250g + 논슬립"으로 잡았던 고정 전략이 **전부 무효**입니다.
→ **클램프 암 고정이 선택이 아니라 필수**가 됩니다.

### 1.2 화면을 보면 손이 시야에서 사라진다

앙와위에서는 화면이 얼굴 위(오버헤드 암)에 있고 손은 몸 옆에 있습니다.
**손을 내려다볼 수 없습니다.** 30~45° 거상에서도 화면이 정면이라 마찬가지입니다.

→ **완전 블라인드 조작이 전제**가 됩니다.
→ **Half-QWERTY가 여기서 더 강해집니다.** 터치타이핑 근육기억이 곧 블라인드 조작 능력이고,
  미러는 "엄지로 누르고 있는 중"이라는 촉각으로 상태를 알 수 있어 화면 확인이 필요 없습니다.
  반면 레이어를 여러 겹 쓰는 방식(천지인 안)은 현재 레이어를 눈으로 확인할 수 없어 불리합니다.

### 1.3 LED 레이어 표시가 무용지물이 된다

v1의 확장 범위에 있던 "LED로 현재 레이어 표시"는 손 옆에 있어 시야 밖입니다.

→ **햅틱(진동) 또는 짧은 비프음으로 교체.** 레이어 진입 시 1회, 복귀 시 2회 같은 패턴.
→ 부품 변경: WS2812B → 코인 진동모터(약 1,500원). 원가 영향 미미.

### 1.4 USB 케이블을 쓸 수 없다

오버헤드 거치된 태블릿까지 케이블을 늘어뜨리면 얼굴·목 위를 지나갑니다.
체위 변경 때마다 걸리고, 안전 문제이기도 합니다.

→ **BLE를 필수 범위로 승격, USB를 충전·설정용으로 강등.**
→ ⚠️ **신청서 §6의 필수/확장 범위가 뒤집힙니다.** 워크숍에서 반드시 다룰 것.

### 1.5 체위 변경마다 재설치하면 안 쓰게 된다

욕창 방지를 위해 통상 2시간 간격으로 체위를 바꿉니다. (확신도 **중간** — 일반적 간호 지침, 원문 미확인)
그때마다 간병인을 불러 기기를 다시 달아야 한다면, 사용자는 **부탁하기 미안해서 안 씁니다.**

이게 이 타겟의 진짜 실패 지점입니다. 성능이 아니라 **부탁의 횟수**가 사용률을 정합니다.

→ 설계 목표를 명시적으로 세웁니다.
> **한 번 설치하면, 체위 변경 후 사용자가 혼자 사용 자세로 복귀할 수 있어야 한다.**

→ 구현: 클램프 암은 침대 프레임에 상시 고정, 기기는 **자석 원터치 탈착**.
  팔을 뻗지 못해도 손등 스트랩에 기기가 매달려 있으면 손 위치만 바꾸면 됩니다.

## 2. Track A — 손가락은 자유, 팔을 들 수 없음

### 2.1 대표 사용자 (안)

**이서준 · 24세 · 근이영양증(듀센형)**
전동휠체어 사용, 온라인 강의 수강 및 웹 개발 독학. 낮에는 휠체어, 밤과 컨디션 저하 시 침상.
어깨·팔꿈치 근력이 크게 약해져 **팔을 들어 올리지 못하지만, 손가락 미세 조작은 남아 있음.**
키보드를 칠 수는 있으나 손을 키보드까지 **가져가지 못하는** 것이 문제.

> 확신도 **중간** — 듀센형이 근위부(어깨·골반)부터 약화되고 원위부(손가락)가 상대적으로 오래 보존되는
> 경향은 일반적으로 알려져 있으나, 진행 단계와 개인차가 큽니다. 당사자 확인 필요.

### 2.2 핵심 판단

**입력 방식은 바꿀 필요가 없습니다. Half-QWERTY 15키가 그대로 유효합니다.**
Track A의 개발 대상은 기기가 아니라 **거치 시스템**입니다.

이건 좋은 소식입니다. 앉은 자세 버전과 **PCB·펌웨어·셸을 100% 공유**하고,
거치 부품만 추가하면 됩니다. 해커톤 기간 안에 두 시나리오를 모두 낼 수 있습니다.

### 2.3 자세별 거치

**앙와위 (천장 보는 자세)**

몸통 위에 올리는 안은 권하지 않습니다. 호흡에 따라 기기가 오르내려 조준이 흔들리고,
복부 압박은 호흡기 사용자에게 위험합니다.

→ **사이드 마운트**: 매트리스 옆 프레임에 클램프로 고정한 암이,
  기기를 **손이 이미 놓여 있는 위치로 가져옵니다.** 손을 옮기지 않습니다.

```
    [오버헤드 암 + 태블릿]
            ▲ BLE
            │
  ┌─────────┴─────────┐
  │   사용자 (앙와위)   │
  └───┬───────────┬───┘
      │           │
   [딸깍]      침대 프레임
   손 옆 고정    클램프
```

- 기기 각도: 손바닥이 위를 향한 상태(회외)로 두고, 키면이 **손가락 쪽을 향하도록 약 70° 세움**
- 손등 스트랩으로 손이 옆으로 흘러내리지 않게 고정
- 볼조인트 + 원터치 레버로 각도 재조정

**상체 30~45° 거상**

훨씬 쉽습니다. 앉은 자세에 가까워집니다.

- 무릎 위 쿠션 테이블 또는 같은 클램프 암을 각도만 바꿔 사용
- 텐팅 20~30°(Half-QWERTY 권장 각도) 그대로 적용 가능
- 이 자세가 **주 사용 자세**가 될 가능성이 높으므로, 시연은 이쪽으로 하는 편이 안전

### 2.4 Track A 추가 부품

| 부품 | 사양 | 단가(원) |
|---|---|---|
| 클램프 암 | 마이크 스탠드용 구즈넥/관절 암 유용 | 25,000 |
| 볼조인트 + 원터치 레버 | 카메라 볼헤드 유용 | 15,000 |
| 자석 마운트 | 네오디뮴 + 얼라인 핀 | 5,000 |
| 손등 스트랩 | 벨크로, 3D 프린팅 브래킷 | 3,000 |
| 코인 진동모터 | 햅틱 피드백 (LED 대체) | 1,500 |
| | **추가 합계** | **약 49,500** |

기존 BOM 96,000 + 49,500 = **약 145,500원**
> 확신도 **낮음(추정)** — 상용 카메라·마이크 부품 유용을 전제한 값. 실견적 필요.

## 3. Track B — 손가락 미세조작이 어려움

### 3.1 대표 사용자 (안)

**정하늘 · 33세 · 경수손상 C6 (교통사고 후 6년)**
손목 신전은 가능하고 어깨·팔꿈치도 일부 쓸 수 있으나, **개별 손가락 분리 운동이 불가능**.
물건은 tenodesis grasp(손목을 젖히면 손가락이 수동적으로 오므라지는 방식)로 집음.
현재 컴퓨터는 스타일러스를 손에 고정해 한 키씩 누르는 방식으로 사용.

> 확신도 **중간** — C6 손상의 일반적 기능 수준. 실제 잔존 기능은 개인차가 매우 큼.

### 3.2 핵심 판단 — 정직하게

**Half-QWERTY의 이점이 여기서는 사라집니다.**
15키를 손가락 하나씩 눌러야 하는데 그 전제가 성립하지 않습니다.
skill transfer라는 우리 논거의 핵심이 통하지 않습니다.

Track B는 사실상 **다른 제품**입니다. 이걸 하나의 기기로 억지로 묶으면 양쪽 다 어정쩡해집니다.

### 3.3 그럼에도 살릴 수 있는 경로 — 설치 없는 화상 키보드 조작

Windows·macOS·iPadOS에는 **화상 키보드가 기본 내장**되어 있습니다.
우리 기기가 표준 HID 마우스로 동작하면, 별도 설치 없이 화상 키보드를 조작할 수 있습니다.
**"설치 권한 불필요"라는 우리 원칙이 Track B에서도 그대로 유지됩니다.**

→ Track B의 딸깍은 **정밀 포인팅 특화 기기**가 됩니다.

| 요소 | 사양 |
|---|---|
| 주 입력 | 손 전체로 감싸 쥐는 **대형 조이스틱** (손가락 분리 불필요, 손목·전완으로 조작) |
| 클릭 | 대형 저항력 스위치 2개 (손날·손등으로도 누를 수 있는 위치) |
| 외부 확장 | 3.5mm 잭 2개 — 기존 보유 스위치(헤드·친·풋) 연결 |
| 감도 | 저속 구간을 더 넓게. 떨림 억제 필터(이동 평균 + 데드존) 추가 |
| 문자 입력 | OS 내장 화상 키보드 |

**속도 정직 고지**: 화상 키보드 방식은 분당 10~20타 수준으로, Track A(목표 100타 이상)와
자릿수가 다릅니다. 발표에서 두 트랙의 속도를 나란히 놓지 마십시오.

### 3.4 Track B가 더 나을 수 있는 지점

Track B에는 Track A에 없는 강점이 하나 있습니다.
**단어 예측·스위치 스캐닝 없이도, 이미 손에 익은 마우스 개념만으로 쓸 수 있다**는 점입니다.
학습 부담이 사실상 0이고, 기존에 쓰던 외부 스위치를 그대로 끌어옵니다.

## 4. 두 시나리오를 하나로 — 공통 코어 구조

사용자가 "두 시나리오 모두"를 선택하셨으므로, 다음 구조를 권고합니다.

```
                    ┌──────────────────────────┐
                    │      공통 코어 모듈        │
                    │  ESP32-S3 · BLE/USB HID  │
                    │  트랙볼 센서 · 배터리      │
                    │  햅틱 · 3.5mm 잭 ×2       │
                    └────────────┬─────────────┘
                                 │ 자석 + 포고핀 8P
         ┌───────────────────────┼───────────────────────┐
         │                       │                       │
   ┌─────┴──────┐        ┌───────┴───────┐       ┌──────┴──────┐
   │ 셸 1        │        │ 셸 2           │       │ 셸 3         │
   │ Half-QWERTY │        │ Half-QWERTY   │       │ 대형 조이스틱 │
   │ + 논슬립     │        │ + 클램프/스트랩 │       │ + 대형 스위치 │
   │             │        │               │       │              │
   │ 앉은 자세    │        │ 누운 자세      │       │ Track B      │
   │ 한 손 사용자  │        │ Track A       │       │              │
   └─────────────┘        └───────────────┘       └──────────────┘
```

- **셸 1과 셸 2는 입력부가 동일**하고 거치 인터페이스만 다릅니다. 실질 개발은 1종
- 셸 3만 별도 설계
- 펌웨어는 부팅 시 셸 ID 저항값을 읽어 자동 전환 (저항 분압 1핀)

**발표 서사**: "하나의 코어, 세 개의 셸. 사용자의 몸이 바뀌어도 기기를 새로 사지 않습니다."
진행성 질환(근이영양증·ALS) 사용자에게 이건 실제로 중요한 가치입니다.

## 5. 개발 범위 재조정 (신청서 §6 대체안)

| 구분 | 기존 신청서 | **변경안** |
|---|---|---|
| 필수 | USB HID | **BLE HID** (누운 자세는 무선이 필수) |
| 필수 | 버티컬 그립 외형 | **텐팅 20~30° + 클램프 마운트** |
| 필수 | 트랙볼, 좌우 클릭, 레이어 전환, 최소 키셋 | **Half-QWERTY 15키 + 미러**, 트랙볼, 좌우 클릭 |
| 확장 | BLE | **USB (충전 겸용)** |
| 확장 | LED 레이어 표시 | **햅틱 피드백** |
| 확장 | 네 손가락 다방향 스위치 전 영역 | **셸 3 (Track B 조이스틱)** |
| 확장 | 키맵 편집 도구 | 유지 (WebHID) |

## 6. 결정 사항 — 오늘 19:30 워크숍

1. **Track A vs Track B 중 택일** (사용자 선택 예정)
   - Track A: 기존 설계 재사용률 높음, 기간 내 완성 확률 높음, 속도 지표로 승부 가능
   - Track B: 재사용률 낮음, 사실상 신규 개발, 대신 중증 사용자 접근성이라는 명분이 강함
   - **권고: Track A.** 남은 기간과 Half-QWERTY 근거를 살릴 수 있고,
     Track B는 셸 3으로 "확장 가능성"으로 제시하는 편이 완성도가 높습니다.
2. BLE 필수화에 동의하는가 (신청서 범위 변경)
3. LED → 햅틱 교체 확정
4. 시연 자세를 30~45° 거상으로 할 것인가 (앙와위보다 세팅이 안정적)

## 7. 수요자에게 확인해야 할 것 (다음 멘토링 / 오늘 남은 시간)

**공통**
1. 하루 중 누워서 컴퓨터를 쓰는 시간이 실제로 얼마나 되나요
2. 지금은 어떻게 쓰고 계신가요 (이게 우리 설계보다 나을 수도 있습니다)
3. 체위 변경 후에 기기를 다시 맞추는 걸 **혼자 하실 수 있어야 하나요, 아니면 도움을 받으시나요**
4. 침대 프레임에 클램프를 물릴 수 있나요 (병원 침대 / 가정용 전동침대 / 일반 침대)

**Track A 확인용**
5. 손가락은 움직이는데 팔을 못 드는 상황, 실제로 흔한가요
6. 화면은 어디에 두고 보시나요 (오버헤드 암 / 벽걸이 / 태블릿 거치)

**Track B 확인용**
7. 손 전체로 감싸 쥐는 조이스틱, 손목만으로 조작 가능하신가요
8. 이미 쓰고 계신 외부 스위치가 있나요 (있다면 커넥터 규격)

## 8. 확신도 정리

| 항목 | 등급 |
|---|---|
| 누운 자세에서 클램프 고정이 필수라는 판단 | 높음 (물리 조건에서 직접 도출) |
