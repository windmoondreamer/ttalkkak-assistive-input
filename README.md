# 딸깍 — 한 손 전용 통합 입력장치

제7회 국립재활원 보조기기 해커톤 · 팀 딸깍
동국대 전자전기공학부 · 김민섭 / 윤홍민 / 장재원 / 김예진

> 한 손만으로 마우스 커서 제어와 문자 입력을 동시에 수행하는,
> 드라이버 설치가 필요 없는 버티컬 트랙볼 통합 입력장치

---

## 문제

뇌졸중 후 편마비·상지 절단·뇌성마비 등으로 한쪽 상지만 쓰는 사용자는
키보드와 마우스 사이를 한 손으로 계속 왕복해야 합니다.

병목은 **키의 개수**가 아니라 **커서 제어와 문자 입력 사이를 오가는 모드 전환 비용**입니다.
그래서 키보드를 한 손 크기로 줄이는 대신, 손을 장치에서 떼지 않고 두 기능을 모두 수행하도록
입력 구조 자체를 다시 설계합니다.

## 핵심 구조

```
[5-way 입력] → [천지인 상태머신] → [자모 확정] → [두벌식 스캔코드] → [OS IME가 음절 조합]
    장치 안                                              │
                                              여기부터 표준 HID
                                              드라이버 · 설치 권한 불필요
```

- **엄지** — 트랙볼(커서) + 좌·우 클릭. 포인팅 전담
- **네 손가락** — 5-way 스위치 4개 = 20입력. 문자·기능 전담
- **한글** — 천지인 파생 배열. 멀티탭을 방향 입력으로 대체해 자음 14개 중 10개가 1타
- **연결** — 표준 HID 복합 장치(키보드+마우스). 설치 권한 없는 회사·학교·공공기관 PC에서 즉시 동작

## 지금 열려 있는 결정

설계 문서 §7 참고.

**팀 합의 필요**
1. 손바닥 반대편 5키 폐지 (그립 상태에서 닿는 손가락이 없음)
2. 천지인 파생 배열 vs 두벌식 레이어 방식
3. 필수 범위에서 BLE 제외 여부
4. `ime_hangul.c` 담당자 지정

**수요자 멘토링 확인 필요**
1. 기기 밀림 — 논슬립으로 충분한가, 클램프가 필요한가
2. 손가락 관절의 방향 입력(밀기/당기기)이 실제로 가능한가
3. 스위치 작동력 상한 (1.0N이 타당한가)
4. 천지인을 실제로 쓰고 있는가 ← **아니면 배열 전제가 무너짐**
5. Backspace가 자모 단위여야 하는가, 음절 단위여야 하는가
