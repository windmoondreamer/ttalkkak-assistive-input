## 0. 지금 이 프로젝트가 무엇인가

**한 손으로 게임을 하는 입력장치.** 원래는 한 손 전용 키보드+마우스였고, 8월 중순에 게임기기로 방향을 바꿨다.

- 대상 플랫폼 — PC(LoL·발로란트) + 닌텐도 스위치
- 접근성 프레임 — 한 손 사용자가 **두 손 게이머와 같은 게임을, 같은 서버에서** 하게 만드는 것
- 키보드 문자입력은 **범위에서 제외**했다. 타이핑은 OS 내장 화상 키보드를 커서로 조작하는 최소한만.

### 1-2. A안에서 살릴 것 — CAD 전부가 죽는 건 아니다

`cad/finger-input-v1/`은 4손가락 × 3방향(좌·중앙·우) 카트리지다. B안은 약지·소지가 파지 전용이므로 **절반은 죽는다.** 그런데 나머지 절반은 오히려 B안에 그대로 필요하다.

| A안 자산 | B안에서 | 근거 |
|---|---|---|
| **검지·중지 프리셋** (`finger_module_index/middle.py`) | **재사용 유력** | B안의 `T1`·`T2`는 `위/누름/아래` 3방향 토글이다. A안 모듈은 `좌/중앙/우` 3방향 — **같은 기구를 90° 돌린 것**이다. 확신도 **중간**, 실제 이식은 검증 필요 |
| **검증 파이프라인** (`validate_geometry.py`) | **그대로 유효** | 기구가 바뀌어도 간섭·행정·공차 검사 로직은 재사용된다. 903 PASS 인프라를 다시 만들 이유가 없다 |
| **P0 지그 · 공차 쿠폰** (`test_fixture/`) | **그대로 유효** | PETG 축공·간극 측정은 폼팩터와 무관 |
| **EVQ-P0E07K 스위치 선정 · 레버비 계산** | **유효** | 저작동력 근거(소지 0.448N)는 접근성 논거로 그대로 쓴다 |
| 약지·소지 프리셋 | **폐기** | 파지 전용 |
| 4손가락 배열 · P1 rail (`integration/`) | **폐기** | B안엔 4손가락 배열이 없다 |
| 2-MCU 구조 · Brook 하네스 | **폐기** | B안은 XIAO 단독 |
| 실패안전 설계(입력 단선 시 중립 복귀) | **개념만 이식** | B안 펌웨어에도 필요한 사고방식 |

> **주의.** `docs/finger_module_final_report.md`에도 "A안/B안"이 나오는데, 그건 **손가락 기구 방식**(직접 3스위치 vs 독립 3패들)이고 위 표의 A/B와 다르다. 그 문서 안에서는 **Variant A/B/C**로 읽을 것. 용어 충돌이니 팀에서 이름을 정리할 것.

## 4. 사라진 파일 — 이 맥에는 없다 (8/16 확인)

`cad/finger-input-v1/README.md`가 참조하는데 폴더에 없는 두 가지다.

- `cad/grip-size-prototypes/putty_cast_v7_support_free/` — **그립 셸 CAD.** B안은 플라이트스틱이라 형상은 새로 잡지만, **손 치수 실측 데이터는 그대로 쓴다.** 없으면 그립 크기를 처음부터 다시 재야 한다
- `references/` — Lalboard 원본 소스 등 참조 자료

**"옮기다 빠졌다"가 아니다.** 8/16에 홈 디렉터리 전체를 `putty_cast` · `grip-size` · `lalboard` 이름으로 훑었고 **이 맥에는 없다.** 깃 히스토리에도 올라간 적이 없다. 따라서 복구 경로는 둘 중 하나다.

1. 다른 팀원 PC나 클라우드에 있는지 확인한다
2. 없으면 **손 치수를 다시 실측한다.** B안 확정으로 그립 형상은 어차피 새로 잡아야 하므로, 치수만 다시 재면 손실은 크지 않다

### 추적하지 않는 것

CAD 대용량 산출물(`printable/`·`variants/`·`renders/`·`integration/` 등 158MB)은 추적하지 않는다.
소스 `.py`와 검증 리포트만 커밋되므로, **STL이 필요하면 `generate_all.py`로 재생성**한다.
로컬 디스크에는 그대로 두었으므로 지금 당장 재생성할 필요는 없다.

`ppt/`의 빌드 산출물(`.pptx`·`.PPT`·`.preview.html`)과 `node_modules/`도 추적하지 않는다.
