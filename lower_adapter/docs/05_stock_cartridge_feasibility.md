## B. 권장 스톡 ↔ 캐리어 연결

```
Priority 1 (기존 나사 재사용)  C1 + C2   M3, 중심선상 (0.35, 60.33) / (0.35, -6.95), 간격 67.28 mm
Priority 2 (기존 외형 위치결정) F1 + F2   Base 밑면 100.0 x 143.0 평면 + 외곽 포켓
```

**권장안 = Priority 1 + Priority 2 조합.** 원본 가공 0.

| 항목 | 값 |
|---|---|
| 위치 결정 | 캐리어 상면에 **100.6 × 143.6 × 2.0 mm 얕은 포켓** (0.3 mm/side FDM 여유) |
| 회전 구속 | Base 외곽의 앞뒤 비대칭 (피벗 기준 −93.6 / +49.4) |
| 체결 | **기존 M3 2개를 연장**. M3×16 → **M3×22** (캐리어 5 mm 관통 + 원래 물림 유지) |
| 하중 경로 | 전단·모멘트 → 포켓 / 인장 → M3 2개 |
| 보강 | 중심선 2점만으로는 그 선 둘레 회전을 못 잡는다 → **포켓이 필수** |
| 대안 | C3~C6 (스프링 훅 나사) 는 Base **윗면**이라 아래에서 못 쓴다. 미사용 권장 |

> M3 2개는 "위치 정확도"가 아니라 **클램핑 전용**이다. 사용자가 요구한
> `registration → shear / screws → clamping` 분담이 그대로 성립한다.

- 고정부(Base / Roll_holder ×2 / Spacer) **전부 덱 아래.** 덱 위 점 0
- 덱 위로 올라오는 것은 **OneGrip 과 Pitch post(그립 소켓 안)** 뿐
- `Spring_holder`(이동, top 착좌면 −8.4) 는 덱 아래 14.4 mm, 스윕해도 개구 안
- ±10° 전 방향 / 중립 모두 고정부 간섭 0

### 권고

```
OPTION C — STOCK GIMBAL CARTRIDGE
```

근거 (사용자가 지정한 순서대로):

1. **인체공학 손 높이** — 경사면 기준 **동률(55.879 mm)**. 스톡 짐벌이 덱을 관통하므로
   "적층으로 손이 높아진다" 는 우려는 실제로 발생하지 않는다.
   고정 바닥 기준으로는 B 가 68 mm 유리하지만, 이는 **지지 형상 문제**이지
   손목 각도/높이 문제가 아니다
2. **구현 리스크** — C 는 검증된 기구를 그대로 쓴다. B 는 FDM 베어링 시트·저널 정렬이라는
   가장 어려운 부분이 **아직 미검증**이고 docs/04 에서 결함 4건이 발견됐다
3. **커스텀 기구 수** — C 는 0, B 는 짐벌 1식 전체
4. **해커톤 신뢰성** — C 는 스프링·홀 설계가 통째로 사라진다. 이것이 B 의 남은 작업 전부다
5. **서비스성** — C 는 나사 6개 풀고 카트리지를 아래로 내리면 끝

**조건:** 덱 아래 약 115 mm 의 공간이 필요하다. 지지 형상이 이를 수용하지 못하면
(예: 평평한 바닥 위 사용 필수 + 총높이 100 mm 이하) **B 로 되돌아가야 한다.**
