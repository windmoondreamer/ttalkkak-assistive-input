## 1. ROOT CAUSE

**변환 부호 오류가 아니다. 어셈블리가 고른 물림 방향이 반대였다.**

후보 A(assembly → grip 변환)와 B/C(OneGrip 인스턴스 / post 축 모호성)를 형상으로 갈랐다.

### A는 배제됨 — assembly → grip 변환은 옳다

`align_reference.py` 1단계가 스톡 Base 의 회전을 **하드코딩된 가정**으로 고르고 있었다:

```
if ts < 0:                       # 그립 프레임에서 꼬리는 -Y
```

캐리어 포켓 바닥면은 100.600 × 100.600 (Base **본체**만)이라 회전을 확정하지 못한다.
회전을 실제로 확정하는 것은 **하우징의 꼬리 슬롯**이다. 두 후보를 실제 부울로 채점했다:

| 후보 | Base 꼬리 | 하우징 간섭 | 캐리어 간섭 |
|---|---|---|---|
| Rz(0) | +Y | **2,621.78 mm³** | 756.91 mm³ |
| **Rz(180)** | −Y | **0.00 mm³** | 0.00 mm³ |

Rz(180)만 슬롯에 들어간다 → 현재 변환이 옳다. 스톡 Base·전장·캐리어 정합은 건드릴 이유가 없다.

### C가 원인 — post 물림의 2-fold 모호성

부착축을 **두 부품에서 독립적으로** 얻었고 정확히 일치한다:

| 출처 | 법선 |
|---|---|
| OneGrip 착좌면 (면적 1,958.16 × 2) | (+0.007857, −0.097373, −0.995217) |
| Pitch 상단면 (면적 445.05) | (−0.007857, +0.097373, +0.995217) |

→ 부착축 **a = (−0.007857, +0.097373, +0.995217)**, grip +Z 에서 **5.6061°**
(= 어셈블리 스냅샷의 Pitch 편향 5.606°).

소켓 보어 내벽 4면의 평면식을 풀어 단면을 구했다: **21.0720 × 25.6720 mm 직사각형**
(문서값과 일치). **직사각형은 축 둘레 180°에 대해 자기 자신으로 간다** →
post 물림이 두 방향 모두 기계적으로 성립한다. 어셈블리 STEP 이 그 중 반대쪽을 담고 있었다.

### 축 통과점

축은 **짐벌 피벗을 지난다**. 측정된 통과점 p0 = (−0.369139, 31.844001, −68.102584) 는
피벗 (0, 27.275842, −114.860854) 을 지나는 직선에서 **0.0068 mm** 벗어나며,
축방향 거리는 **46.982 mm** 다 (CLAUDE.md 의 "플랜지면 아래 46.98mm" 와 일치).

9자세 캐시의 `Pitch` 점군 Kabsch 로 교차검증했다 — **전 자세에서 피벗 이동 0.0000 mm**,
중립 자세 축 = **(0, 0, 1) 정확**, Kabsch 잔차 ≤ 3.4e-12 mm.

**교정 = 축 (a, p0) 둘레 180° 강체 회전, OneGrip 상부에만 적용.**

## 2. 방향 불변량 (신규)

`build123d/grip_orientation.py` + `fix_grip_orientation.py`.

- **`GRIP_FORWARD_VECTOR`** — 손잡이 상단이 기우는 수평 방향. 그립 샤프트 주축(PCA)을
  데크 평면에 투영. SIDE 프리뷰에서 눈에 보이는 바로 그 방향이고, 비대칭이라 180°를 구분한다.
- **`WRIST_SUPPORT_DIRECTION`** — 하우징에서 유도. (ERGO − CORE) 재료의 도심 − 코어 도심,
  XY 투영. 상수를 손으로 넣지 않는다.
- **게이트: `dot(GRIP_FORWARD, WRIST_SUPPORT) < 0`**

```
WRIST_SUPPORT_DIRECTION       = (-0.018424, -0.999830, +0.000000)

GRIP_FORWARD_VECTOR  before   = (+0.194424, -0.980918, +0.000000)
GRIP_FORWARD_VECTOR  after    = (-0.146334, +0.989235, +0.000000)

(교차검증) 엄지패널 before      = (+0.020375, +0.999792, +0.000000)
(교차검증) 엄지패널 after       = (-0.349631, -0.936887, +0.000000)

dot  before = +0.977169   (사이각  12.267 deg)   -> FAIL (반전 상태)
dot  after  = -0.986371   (사이각 170.530 deg)   -> PASS
```

**이 검사는 20°/90°가 전부 통과하는 상태에서 반전을 잡아낸다.** 그게 목적이다.

## 4. 모션 검사 — **TRANSFORMED / CACHED ENVELOPE**

캐시 `motion_configs.npz` 에는 OneGrip 상부가 들어 있다 (덱 위 점 2,468,801개:
`Joystick_1/2`, `Backplate`, `HW504_B ×2`, `Small_joystick_attachment`).
따라서 **그대로 재사용하지 않았다.**

자세마다 그 자세의 부착축 (피벗, B_k·ẑ) 둘레로 **그립 점만** 회전시켜
`motion_configs_gripfix.npz` 를 새로 만들었다 (`fix_motion_envelope.py`).

| 자세 | Kabsch 잔차 | 피벗 고정 | 축 각도 |
|---|---|---|---|
| neutral | 2.8e-14 | 0.0000 | 0.0000° |
| X±10 / Y±10 | ≤1.6e-12 | 0.0000 | 10.0000° |
| 코너 4 | ≤2.0e-12 | 0.0000 | 14.1060° |

회전된 점 **2,567,430**개. **스톡 이동부 점군은 완전 무변화** (배열 동일성 확인).

결과: 9자세 전부 `0 / 20,130 점`. **이 검사는 DIRECT BREP 이 아니라 TRANSFORMED/CACHED 다.**
어셈블리 스냅샷 한 자세에 대한 검사는 DIRECT BREP 이고, 신규 간섭 −0.000000 mm³ 다
(전체 138.2772 = 동결 코어가 이미 갖고 있던 나사 머리 4개분, W2 기여 0).
