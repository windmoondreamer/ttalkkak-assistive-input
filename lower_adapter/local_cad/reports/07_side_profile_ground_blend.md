# SIDE 하부 프로파일 우선 지면 블렌드 — A / B

**방식: 2D SIDE 하부 프로파일을 먼저 설계·검증하고, 그 함수에서 각 단면의 bottom Z 를
직접 계산해 3D 에 반영했다 (§5, §12).** 상부 실루엣·그립 방향·하부 기구는 손대지 않았다.
Onshape API 호출 0건. 기존 `ERGO_HOUSING_W2.step` 은 덮어쓰지 않았다.

---

## 1. 좌표 관계 — 이번 설계를 가능하게 한 식

등Y 단면(현재 전면 형상)을 (u, h) 로 보내면

```
h = 2.92397·y − 2.74766·u + 171.326109
z = (0.9397·y − u) / 0.342
```

즉 **등Y 평면은 (u,h) 에서 기울기 −2.74766 = 70.0° 인 직선**이다.
지금 전면이 월드에서 70° 로 보이는 이유가 이것이고,
동시에 이 식 덕분에 하부 프로파일 `h = f(u)` 만 주면
각 단면의 bottom Z 를 이분법으로 **직접 풀 수 있다** (§12, `side_profile.zbot_for_y`).

## 2. 현재 상태 (실측)

```
손목 앞끝            u = -81.89
첫 접지              u = -24.89
floating span        57.00 mm
하부 최대 상승각     71.23°
```

즉 손목 받침 앞 57 mm 가 공중에 뜬 채 하부가 71° 로 치솟는다.

## 3. 하부 프로파일 두 안

제어점을 **단조 3차 Hermite (Fritsch–Carlson)** 로 보간한다.
단조성을 보장해야 하부가 도중에 되올라가지 않는다. scipy 없이 직접 구현했다.

```
PROFILE A   (-81.89, 5.0) (-76, 3.2) (-70, 1.6) (-64, 0.5) (-60, 0) (-50, 0)
PROFILE B   (-81.89, 5.0) (-78, 3.6) (-73, 2.0) (-69, 0.8) (-67, 0) (-55, 0)
```

마지막 두 점을 h=0 으로 두 번 둬서 **지면 접촉부 기울기가 정확히 0** 이 되게 했다
(§7 near-tangent).

| 2D 지표 | 현재 | **A** | **B** |
|---|---|---|---|
| 첫 접지 u [mm] | −24.89 | **−60.00** | **−67.00** |
| floating span [mm] | 57.00 | **21.89** | **14.89** |
| 앞끝 립 높이 [mm] | — | 5.00 | 5.00 |
| 하부 최대 기울기 [°] | **71.23** | **15.82** | **28.15** |
| 지면 접촉 기울기 [°] | — | **0.00** | **0.00** |
| 립 앞끝 Y [mm] | — | −134.36 | −134.36 |
| 첫 접지 Y [mm] | — | −114.98 | −121.56 |

A 는 §9 의 "ground contact −58~−62 / lip 20~24 mm", B 는 "−65~−70 / 12~17 mm" 를
그대로 만족한다.

## 4. 3D 반영 방식

- 각 손목 단면의 **bottom Z 를 `f(u)` 에서 직접 계산**한다 (loft 결과에 맡기지 않는다).
- **상부 규칙은 손대지 않았다** — 앞으로 확장한 단면들도 top = 패드 평면이다.
- 전면은 **월드 수직 평면 `u ≥ −81.89`** 으로 잘라낸다. 손목 앞끝 u 를 그대로 두면서
  지금의 등Y(70°, 오버행) 전면을 수직면으로 바꾼다.
- 뜬 립 구간과 지면 구간의 **중공 방식을 부드럽게 전환**한다
  (`s = clamp((2 − h)/1.8, 0, 1)`):
  s=1 지면 구간은 아래로 열어 두고(서포트 불필요), s=0 뜬 립은 바닥을 닫아
  벽 두께를 균일하게 유지한다. 두 값 모두 y 에 대해 연속이라 loft 에 단차가 없다.

단면표 (밑면 = 지면 위 높이):

```
A   5.0 → 3.6 → 2.3 → −6.4 → −15.0 → −18.8 …
B   5.0 → 3.4 → 0.9 → −16.9 → −18.8 …
```

음수는 지면 아래로 내려 지면 절단이 **곧은 구간**을 자르게 한 것이다
(코너 R16 이 안쪽 단면에 먹혀 4.88 mm 뜨는 기존 결함을 피한다).

## 5. 중간에 잡은 결함 1건 — `sfac` 블렌드가 프로파일을 망가뜨렸다

처음에는 뜬 립 구간과 지면 구간의 중공 전환을 부드럽게 하려고
`s = clamp((2 − h)/1.8, 0, 1)` 로 **바깥 밑면까지** `zb − 20·s` 로 블렌드했다.
그 결과 전환 구간의 밑면이 프로파일보다 낮아져 지면에 일찍 닿았다:

```
설계        접지 u = -60      하부 최대각 15.8도
1차 실측    접지 u = -70.9    하부 최대각 84.4도
```

불연속은 어차피 **지면 아래**에서만 생기고 지면 절단이 지운다.
그래서 하드 스위치(`hp <= 0.05`)로 바꿨고 재빌드 후 밑면이 프로파일을 정확히 따른다.

```
A   5.0 → 3.6 → 2.3 → 1.3 → 0.5 → 지면
B   5.0 → 3.4 → 0.9 → 지면
```

**측정 지표 정정 1건:** 하부 최대 기울기를 u ∈ (−90, −15) 전 구간에서 재면
두 안 모두 84.4° 가 나오는데, 그 지점은 **u = −35.9 의 국소 노치**,
즉 동결 코어가 원래 갖고 있는 **스톡 전장 꼬리 관통 슬롯**이다.
블렌드와 무관하므로 지표를 **앞끝 ~ 첫 접지 구간**으로 한정했다.

실측 하부 실루엣 (A):

```
u  -81.89  h 4.655           u  -73.89  h 2.309   9.2도
   -79.89    3.951  19.4도      -69.89    1.275  14.5도
   -77.89    3.277  18.6도      -65.89    0.260  17.7도
   -75.89    2.631  17.9도      -63.89    0.000   7.4도  <- 접지
```

## 7. 검증 — 두 안 모두 23 PASS / 0 FAIL (§27)

- 그립 방향 불변량 (교정 후 부호 유지) PASS
- 기준면 vs 수평 **20.000000000°**, 그립 중립축 ⟂ 기준면 **90°**
- HAND_REF 무변경, 덱→HAND_REF **55.8785**, 지면→HAND_REF **161.0208**
- 피벗 / 스톡 Base / 캐리어 위치 무변경, 스톡 돌출 **0.0000 mm**
- 캐리어 −Z 인출 0–100 mm 무충돌 (DIRECT BREP)
- 9자세 모션 **전부 0 / 20,130 점** — `motion_configs_gripfix.npz`
  (**TRANSFORMED / CACHED MOTION ENVELOPE CHECK**, DIRECT 아님)
- 새 외피가 **추가한** 나사 간섭 **0.000000 mm³**
  (동결 코어의 기존 138.2772 mm³ 는 범위 밖, NOTE 유지)
- `NEW & FROZEN_HOUSING` = 코어 전체 포함, 단계별 BREP 전부 valid (§17)

| 근거 | A | B |

둘 다 지면 접촉 기울기는 설계상 0° 이고 71.33° → 19~28° 로 개선폭이 압도적이라
이 차이는 취향 범위다. 길이·폭·높이·부피는 사실상 동일하다(부피차 636 mm³).

### 남은 항목

- `WRIST_SIDE` 필렛은 모서리가 208~210개로 늘어 캡(80)에 걸려 생략됐다.
  기준 W2 는 개별 R2 로 32개가 걸려 있었다. 선택 후 캡을 올려 재적용할 수 있다.
- §23 의 `GROUND_TRANSITION_EDGE` 그룹은 아직 만들지 않았다.
  립 앞끝 모서리(전면 수직면 ∩ 하부 곡면, 끼인각 A 70.6° / B 62.4°)에
  작은 필렛을 넣으면 립이 더 자연스러워진다.
- STL 은 §24 대로 선택 후 생성한다.
